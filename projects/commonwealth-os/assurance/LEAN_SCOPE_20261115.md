## Claimed Lean statements

* `transcript_sound_iff_cover` is an exact equivalence of soundness and an unsafe-world hitting set for deterministic named observations. `exists_least_cost_sound_panel` proves existence of an optimal finite query panel with natural-number total costs whenever a sound panel exists; it **does not** prove that an implementation finds it efficiently.
* `empty_evidence_rejected` blocks vacuous empty-world certification; `valid_evidence_actual` requires actual-world inclusion.
* `same_world_composition` proves component-wise claims combine only over one declared possible-world scope.
* `accept_preserves_safe`, `sink_step_preserves_safe` and `reachable_sink_safe` prove conditional safety/replay exclusion for **atomic transitions in a sequential abstract ledger**; they do not prove an actual SQL or third-party effect transaction is linearizable.
* `indistinguishable_authority_impossibility` formalizes stale-evidence obstruction. `ledger_evidence_implies_authority` and `reachable_evidence_guard_authority` explicitly compose the evidence certificate and the atomic sink, proving every recorded effect is authorized at its true commit-time world and no effect ID appears twice under the declared guard.
* `recertification_transfer` requires both world-set refinement and unchanged semantic meaning; there is no automated proof that a changed jurisdiction satisfies these premises.

## Exact external assumptions not proved

1. Authoritative jurisdiction/legal interpretation, valid delegation, rights and operative rules are supplied truthfully by competent independent reviewers.
2. Relevant eligibility, quorum, ballots, tally, secrecy/coercion conditions are verified using separately audited election protocols and actual institutional evidence.
3. The actual current world is included among the authenticated worlds and stays under a coherent snapshot through verification and atomic commitment.
4. Every relevant physical/administrative effect is mediated by a correctly implemented, linearizable sink; revocation and source changes cannot bypass it.
5. The realized Python, JavaScript and database programs refine their Lean abstract semantics. No such refinement proof exists yet.
6. Human informed agency, equal effective access, human-rights constraints and operational liveness require empirical/institutional evidence, not this finite proof alone.
