# Commonwealth OS — Figma import wireframes v1.2

Target Figma design file: https://www.figma.com/design/reZeEFA8DfQL9G51AvHdqW

These six **SVG vector wireframes** were prepared as a fallback because the connected Starter-plan Figma MCP limit blocked writing to the design file. The Figma file currently exists but is not populated by this package.

## Import
Open the file above. Drag the six numbered `.svg` files from this folder into the Figma canvas in numerical order, or use File > Place image. Figma may convert SVG text to outlined vectors depending on import behavior; these are vector-editable import assets, not guaranteed fully editable Figma-native text/auto-layout layers.

Sequence: Welcome → Optional Survey → Living Voter Dashboard → Exact-Question Briefing → Nonbinding Vote Simulation → Historical Roll-Call Comparison.

The comparison correctly separates an exact matched House vote from two unrelated Senate procedural examples. It does not infer political stances from procedural votes or missing records. Users' simulated choices and survey answers must not be represented as actual ballots.

Official sources: https://clerk.house.gov/evs/2026/roll297 ; https://www.senate.gov/legislative/LIS/roll_call_votes/vote1192/vote_119_2_00259.htm ; https://www.senate.gov/legislative/LIS/roll_call_votes/vote1192/vote_119_2_00262.htm
