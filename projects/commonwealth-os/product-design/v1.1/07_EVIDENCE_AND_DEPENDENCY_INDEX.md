4. A previous 79-test app integration receipt does not assert 79 tests pass for a current main that no longer contains the same source files.
5. Standalone historical/ and public civic intelligence website are useful implementation assets, but neither alone answers personally represented officials since DOB with date-effective residence and district evidence.
6. An asserted source digest validates equality to bytes, not the lawful custodian, source completeness, result interpretation, electoral authority or independent review.
