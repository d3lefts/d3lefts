## Preservation and migration rules

Avoid massive physical path moves while manuscripts, GitHub URLs, website references and external reviewer scripts still cite their locations. Create canonical **indexes pointing to primary sources** and add redirect notes only after verifying link migrations. If a file is intentionally relocated in a later version, keep an immutable source tag, exact bytes and SHA-256, a `MOVED.md` pointer at the old path, all links updated, and a dedicated regression check.

New candidate results remain in active research, even when their inherited source ZIPs were historically placed in `research/new-moon/`. Lifecycle is an explicit [catalogue field](../catalogue/CLAIMS.json), not an implication of an inherited directory name.

No blanket license is presently granted; see [rights notice](../REUSE_AND_RIGHTS.md). Owner authorization precedes public releases, external submissions and citation/rights changes.
