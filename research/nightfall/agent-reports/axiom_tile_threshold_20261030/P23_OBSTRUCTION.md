# p=23 structural transition: finite template obstructions, not a universal no-go

**Status:** R1 review construction, October 31 2026. Internal AI-assisted exact computations; no external referee, no global priority. Do not merge into production or claim global impossibility.

## Frozen problem

Let G=(F23)^2 be the additive group of K=GF(23²). For a binary cube
T={Σ ε_i w_i: ε_i∈{0,1}}, with eight generators, we seek |T|=256 and a translation c such that squaring is injective on c+T. The squared-output alphabet has (23²+1)/2=265 values, so eight signs are information-theoretically possible. The existing product/diamond constructions guarantee seven.

**Exact criterion:** Squaring is injective on c+T iff the restricted/off-diagonal sumset
T ⊕ T={u+v: u,v∈T, u≠v}
does not contain m=−2c. The ordinary sumset-hole condition m∉T+T is sufficient but not necessary: an m=2u with a single diagonal representation is harmless. For odd-order G, every m has at most one diagonal representation; therefore if every m has ≥2 ordered pair representations in T+T, the restricted sumset is full and **no translation can yield an injective square code**.

## Finite complete enumerations within stated templates

The axis base B=[0,2^a−1]×[0,2^b−1] is generated by a+b axis powers. Add arbitrary shifts v,w (two shifts) or v,w,t (three shifts), always requiring every binary subset sum to be distinct. Normalize v<w to remove exchange duplicates; t ranges over all 528 nonzero shifts.

| Base | Extra shifts | Valid candidate codes | Sumset holes | Restricted sumset holes |
|---|---:|---:|---:|---:|
| 8×8 | 2 | 12,800 | 0 | 0 |
| 16×4 | 2 | 21,160 | 0 | 0 |
| 4×16 | 2 | 21,160 | 0 | 0 |
| 8×4 | 3 | 2,153,616 | 0 | 0 |
| 16×2 | 3 | 5,840,160 | 0 | 0 |

Axis swaps give the corresponding 4×8 and 2×16 cases. In the first three rows these exhaust all axis bases with six generators (any longer axis alone would violate injectivity). In the last two rows they exhaust all axis bases with five generators up to axis swap. **They do not cover four-axis-generator bases with four arbitrary shifts, nor general eight-generator configurations.**

## Reproducible independent checks

- p23_template_search.py: pure-Python exact 529-bit masks, OR across every modular translate; 12,800/21,160/21,160 two-shift valid counts, plus 53,640 valid four-tile intermediates and 2,153,616 eight-tile three-shift candidates for the 8×4 base. All ordinary sumsets cover G.
- p23_two_shift_offdiag.py: independently computes convolution multiplicities for each valid two-shift cube and proves no sum has only a diagonal representation.
- p23_offdiag.cpp: independent C++ ordered-sum convolution audit for all 2,153,616 valid 8×4 + three-shift cubes. Every group element has an off-diagonal pair sum. Only 8 extreme shifts times four multiplicity-one base corners need inspection: if a sum has exactly one ordered representation, it must lie in this finite candidate set.
- p23_16x2_three_shift.cpp: independent C++ audit of 5,840,160 valid 16×2 + three-shift cubes. Ordinary sumsets are full. Since every element of the 16×2 base's ordinary pair sumset already has ≥2 ordered representations, so does every represented element of the complete cube. Thus the restricted sumset is also full.

**Checker trap caught and repaired:** When a modular rectangle is longer than 23, integer addition of 1<<index masks is WRONG: repeated residues cause binary carries. Masks must be formed with bitwise OR. A transient false positive for 16×2 was rejected by this check. The committed Python checker uses OR. This is an explicit audit lesson, not a discovery claim.

## Symbolic repair to diamond PR #279

The original nine-rectangle proof said only (a,b)=(2,0) contributes to the slice y*=5D/2−1 among the n=2 rectangles. This omits (a,b)=(0,2), whose negative-D y interval wraps into [p−D,p−1] and also intersects y* when 3D≤p≤7D/2−1. Both contributing rectangles have x shift 2D and the same horizontal range, so the claimed missing x remains valid. DIAMOND_THEOREM.md on this review branch contains the corrected statement. This is an algebraic correction, not external proof review.

## Decision / cheapest next experiment

**No eight-sign code found at p23; no universal impossibility proved.** All axis-rectangle templates with at least five axis bits are now excluded by exact finite enumeration. Switch representation to a four-axis-generator base with four non-axis shifts, or an algebraic/projective construction not constrained to axis rectangles. Seek a true general structural bound before another unstructured search. Preserve all failed families.

Prior-art context: classical dissociated sets and restricted pair sums, including the published "On Unique Sums in Abelian Groups" (Combinatorica 2024), and the 2026 Han–Ren work on restricted sumset covering. Neither source has been established to settle this exact powered-linear oracle.
