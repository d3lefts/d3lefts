## Frozen target

For every x∈GF9^8, including zero and unknown support, an adaptive experiment selects a∈GF9^8 based only on prior observed squares y=(a·x)^2; outputs exactly five symbols (zero plus four nonzero squares). Recover x modulo one **global sign** ±. Claim candidate: eleven queries always fail, twelve suffice using Vesper's already-pending upper construction. Nonadaptive linear-square code length is a **different** quantity; algebraic invariants unrestricted in degree are a **different oracle**.

The proof now has two genuinely separate dependencies: (1) online rank/relative-phase adversary for all adaptive measurement trees, including dependent rows; (2) exact **seven-signed-sum Fourier obstruction** in GF9 additive group F3², forcing a 14-word fiber among 64 relative-sign classes for any dependent eighth row. The second condition is proved analytically in FOURIER_LEMMA.md by signed power-of-two Fourier eigenvalues, with exhaustive independent checkers as negative-control evidence.
