# Gate C — matched-budget Observatory transfer experiment

**Frozen design draft:** 2026-10-28; register by Git commit before running outcome-generating trials.  
**Current status:** awaiting fixed task inputs and external second-path reviewer; **no results exist**.

## Question

Does an explicit graph of scoped mathematical claims and typed transfer prerequisites improve the selection of productive next research checks, measured against an identical flat-source archive under an equal budget?

## Predeclared experimental unit and baseline

Use a **fixed set of six frozen challenge prompts** from the source archive: two finite-field reconstruction audits, two Werner extension checks and two finite-rank spectral coupling audits. Pin all source bytes, repository commit, closest prior art, task text, allowed tools and total compute budget in the pre-run manifest. Include at least one known failing challenge hidden from the operators to test overclaim detection.

Compare **Graph condition G** (same frozen source archive plus Observatory claim/edge registry) with **Flat condition F** (same archive in an indexed chronological list without edges). Both receive identical prompt wording, candidate-set access, permitted model/tool versions and **2000 input+output model tokens and 20 external tool calls per challenge**. Shared mathematical computation allowances must be counted identically. If the chosen model requires more resources, freeze an adjusted equal budget **before the experiment** with a new version.

## Blinding and randomization

Fixed seed `1729`; alternate condition order by frozen randomized task pairing. The evaluators who judge outcomes must see masked source condition labels. The graph condition sees edge types and hypotheses, while flat sees all identical scientific sources and the same search capability; no hidden answer labels or future test results are allowed into either representation.

## Primary and secondary endpoints

Primary: number of tasks yielding a **correctly identified decisive scientific next test** with a reproduced exact acceptance condition under budget. An independent adjudicator grades outcomes from a predeclared rubric without seeing assigned condition.

Secondary: false implication claims, unsupported theorem promotion, valid obstruction detection, number of source files inspected, tool calls, and total compute/token expenditure. Publication includes individual outcomes and negative findings, never only a favorable mean.

## Success and failure

For Gate C evaluation completeness: all six paired task inputs/outputs, frozen manifest, exact per-arm budget accounting, blind adjudication rubric, source hashes and replay scripts must be public. A valid null/negative result is acceptable. A claim of improved discovery requires a positive comparative effect with confidence/uncertainty appropriately scoped, plus reproducible independent validation. Six challenges alone cannot support sweeping population claims.
