## Operators and transfer graph

1. **Dependency-scoped negative certificates.** [788ea467](https://github.com/Belobug/VIctory-Belobug-AMD/commit/788ea4676ec7ddf11ff35ac213afa83d828cfa4c) records smallest failed contiguous-slot request since last release; skips larger requests and adds an eight-failed-walk frame budget. Transfer: cache a failed exact search with canonical instance identity, proof/checker, monotonicity direction, dependencies, and invalidation event. Distinguish exact infeasibility from timeout, budget rejection, heuristic miss and unknown. Never let the budget cap masquerade as an infeasibility certificate. Source comments report 7–11-second frames before change; no independently checked speedup for this patch.
2. **Snapshot, query, revalidate.** [e11fb061](https://github.com/Belobug/VIctory-Belobug-AMD/commit/e11fb061c649a2bd7df57438e24d1c595090fef0) snapshots candidate tiles, performs region queries outside locks, checks last-use and retention state before removal, logs elapsed work. Transfer: expensive verification outside orchestration lock; commit only against identical artifact/dependency digests and lease; otherwise retry. Timestamp equality alone may suffer ABA, so use monotone revisions or content hashes plus lease.
3. **Absence of observation is not absence of dependency.** [0a32e89c](https://github.com/Belobug/VIctory-Belobug-AMD/commit/0a32e89cf58af8a77fabdcf248c82a9d7916889f) records failure of age-based reclamation and offers stricter mode requiring observed unmapped memory; off by default. Transfer: preserve proof dependencies and research state unless reachability and ownership support reclamation. Recheck lifetime races; source's stronger mode is not a proof of safety.
4. **Alias-complete invalidation.** [71652a2c](https://github.com/Belobug/VIctory-Belobug-AMD/commit/71652a2c15a0da68cd801890e1f71109670f9ca5) documents tracking writes across all views of one physical page. Transfer: index artifacts by canonical content and transitive dependency, not path or persona; invalidate all aliases on changed premises. Vehicle correction reported; causal link to tree behavior explicitly unproved.
5. **Localized fault containment and typed fallbacks.** Pinned README/architecture describe per-pipeline compiler failure containment, preflight import census, host allow policy, trapping or zero-return stubs, local stand-in fixture, explicit diagnostic-only switches, content-addressed conversion cache and offline design. Transfer: isolate independent checker tasks, require safe default failure for certification, mark approximations/unsupported cases as such, use fixtures before full integration. Host allow policy is not an independently established sandbox; docs note other paths may pass through. Returning zero or skipping a stage cannot count as successful proof. Cross-build cache reuse requires explicit compatibility evidence.
6. **Differential intervention.** Diagnostics permit alternate backend, targeted substitution, forced refresh and per-stage timing. Transfer: change one mechanism while holding input, environment and checker fixed; measure stage cost and final success separately. Upstream reports 628 additional translations accepted by DXIL validator; live rendering for those changes was still untested. Syntax/validator acceptance is not end-to-end semantics.

## Formalizable operator (elementary, proposed transfer)
Let F_t be the feasible witness set for a fixed query after transition t. If a certified empty set F_0 is followed only by restrictive transitions F_{t+1} subseteq F_t, every F_t remains empty by inclusion. More generally, with nested requirement sets F_t(k+1) subseteq F_t(k), an exact failed query at k excludes all k' >= k until a transition can enlarge feasibility. A timeout proves neither emptiness nor monotonicity. This is a direct set inclusion observation, not a novelty claim. Source allocator's eight-walk cap is a separate heuristic, not covered; completeness of its scanner, lock and concurrency semantics not certified here.

## Cheapest decisive experiment (not yet run)
Prediction: certificate-scoped negative caching reduces repeated solver invocations on restrictive transitions while producing exactly the same accept/reject/unknown outcomes as uncached exhaustive enumeration. Alternatives: wrong dependency key, enlargement without invalidation, heuristic failures promoted to exact negatives, scheduling cap starvation. Freeze deterministic synthetic traces over 8-bit free-slot masks and request lengths 1–8: exhaustive oracle enumerates every legal contiguous interval; independent checker uses maximum free-run length. Include restrictions, releases, same-path changed hashes, alias updates, stale worker results, and budget interruptions. Compare uncached, exact cache, and deliberately broken cache; measure calls, false suppression, stale commits and cost. Require zero false suppression/stale acceptance; broken control must fail. Then use matched traces from real orchestration, reserve 20% of effort for other operator families. No agent reliability or discovery-rate claim until paired trials with independent grading.

## v1.1 follow-up — 2026-11-25: eight additional commit diffs and finite replay

Source remains pinned to 71652a2c. Additional review: f2cc1009, 579a8d9d, e7e6c00b, 1c7231d9, ae909379, 4cbe9d76, cf62e1ae, 03629f3f. The following are proposed transfers, not new scientific priority claims.

- **Correction to operator 4 (alias completeness):** [ae909379](https://github.com/Belobug/VIctory-Belobug-AMD/commit/ae909379e6a401e30e424347544b2e8aec7be5dd) explicitly limits joint guarding to at most 64 views and describes address-based runtime writes as a shortcut. The source is not universally alias-complete; the stronger NIGHTFALL requirement is a proposed design invariant. The same patch provides three diagnostic refresh modes to discriminate distinct stale-copy mechanisms. Use selective invalidation versus full recomputation as a causal ablation, not a success-metric substitute.
- **In-flight work is not complete when the launching call returns.** [579a8d9d](https://github.com/Belobug/VIctory-Belobug-AMD/commit/579a8d9dd96f803df82cf34f0d0e5aa5f9705557) protects asynchronous writes against premature reguarding using a two-second pin and repeated dirty reporting. Transfer: explicit completion acknowledgments, revisioned leases and uncertain state until termination is observed; expiration is not proof of completion. The source timer is a heuristic, not a correctness guarantee.
- **Batch optimistically, split on failure, reconcile per item.** [e7e6c00b](https://github.com/Belobug/VIctory-Belobug-AMD/commit/e7e6c00b33d295870d78a9a05f65408cb50a846f) falls back from failed contiguous protection changes to individual blocks; [f2cc1009](https://github.com/Belobug/VIctory-Belobug-AMD/commit/f2cc1009a73fc93c704fdc57ec2baf300aaa72a3) amortizes alias lookup under a lock. Transfer: batch independent checks and split failed batches; only mark success for confirmed per-item outcomes. The original patch ignores individual protection-return values; do not transfer that weakness. For isolated deterministic single-fault batches, recursive bisection needs at most 1+2 ceil(log2 n) batch probes including the first failed batch, when both halves are probed at each level; not a bound for interacting or nondeterministic faults.
- **Reconcile control-plane state against observed state without broadening authority.** [1c7231d9](https://github.com/Belobug/VIctory-Belobug-AMD/commit/1c7231d9e02c6b193cac5c167d613080f1bfab25) repairs mismatch between tracked protection and actual protection. Transfer: reconcile stale job/receipt records against authoritative worker state; unknown ownership fails closed, never generalize a local fault-recovery heuristic into an authority bypass.
- **Controlled component substitution and boundary-specific semantics.** [cf62e1ae](https://github.com/Belobug/VIctory-Belobug-AMD/commit/cf62e1aeaa69b17eb5b40ac1117badec94f0286c) supports hash-indexed diagnostic substitutions; [03629f3f](https://github.com/Belobug/VIctory-Belobug-AMD/commit/03629f3f0d3f3329052e05084440aeee75ce3107) corrects helper-lane semantics at triangle boundaries. Transfer: matched substitution of research components under frozen contracts, explicit boundary cases, and independent semantic checks. Same interface is not semantic equivalence. The source's 16-digit diagnostic lookup is not a full identity certificate.

### Executed finite replay
Artifact: [replay-negative-cache.cjs](replay-negative-cache.cjs), standalone original JS, no upstream code copied. Run: `node replay-negative-cache.cjs`. Executed the same replay function in a JS runtime before writing the file. Budget: exhaustive ordered pairs of 8-bit masks and first/second requests 1–8, 4,194,304 cases; stop on any mismatch, false suppression, or failure of negative control. Oracle enumerates candidate bit intervals; candidate scanner counts consecutive free bits. These are distinct implementations authored in the same session, not independent non-author review. Cache only skips when the first query fails, the second threshold is no smaller, and the next mask is a subset of the first.
