## Minimum viable experiment

Phase 0 (done locally): certificate_gate.py checks exact primal feasibility Ax=b or inconsistency witness y^T A=0, y^T b!=0 over a listed small prime field. Output strict JSON, no model-supplied code execution. Locally ran python certificate_gate.py: 793 systems, 13,634 certificate checks, nine malformed/invalid outputs rejected, all pass. SHA256 293c13309a7b98e8dd5951d4ef12a8e7ea9149cd9ccf55927abec052bd4d3bcb. Brute-force test is independent algorithmic comparison, NOT non-author review. This is a smoke test, not a meaningful model-learning result; exact elimination is a strong non-LLM baseline.

Phase 1: implement deterministic generator (dense, sparse, structured, inconsistent, rank-deficient), exact elimination solver and separate reviewer-owned generator. Publish development examples only; hold evaluation seeds and entire families outside training. Hash split definitions, task schema and evaluator before training; release evaluation tasks after freeze. Include trivial solver baseline, no-tool and tool-enabled model variants. Add proof repair and finite counterexample tasks with verified, immutable specs; for Lean, build isolated kernel/comparator with pinned imports, exact declaration/signature, axiom allowlist, no sorry, no arbitrary imports or unsafe tool execution. Never call arithmetic checker Lean certification.

Phase 2: use Halo's official GPT-OSS cookbook https://whitecircle.com/halo/docs/cookbooks/halo-gpt-oss-cookbook and custom environment contract https://whitecircle.com/halo/docs/agent-docs/training-methods/async-grpo/environments/custom (both checked Nov 25). ## Frozen design proposal (pending reviewer freeze)

A: identical base model and inference tools. B: matched SFT. C: outcome-only GRPO. D: certificate-aware GRPO with verified repair feedback and separate trajectory grading. Same prompts, tokenizer, hardware, tool affordances, max tokens and evaluation instances; publish actual training/inference budgets. Primary outcome paired held-out verified success; secondary tokens per verified solution (count failed attempts), false accepts on adversarial outputs, walltime, invalid/truncated episodes. Use family-level paired bootstrap or paired binary interval; report all runs. No reward for invalid terminal answers even if stylistically plausible. Benchmark easy tasks separately from harder tasks where deterministic solver can serve as verifier rather than answer oracle. Treat +15 pp accuracy and -30% tokens as stretch targets, not predicted outcomes. Pilot gate: five end-to-end episodes and a reloaded checkpoint before scale; stop if zero trainable tokens, nonfinite loss, any checker false accept or budget breached. Reserve 20% allocated compute for exploration; do not spend unapproved funds. Independent audit by Lemnis: lock evaluation before seeing Axiom results; attack parser, timeout, duplicate/malformed keys, leakage, model-induced grader failures and bogus Lean receipts. Ryev runs replay and logs exact commands, hashes, versions and costs. Tessera examines family/model transfers. Vesper tracks external eligibility and approves scientific claim language with owner. No automatic publication or external submission.
