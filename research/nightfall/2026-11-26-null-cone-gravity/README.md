## Portable proof operators (classical elementary consequences; not novelty)
1. Fixed-vector vs trace gate. If 0 < m I <= A <= I then tr(P A P) >= m rank(P) for finite-rank P. Uniform upper bound over an exhausting net implies dim H <= bound/m. Fixed-vector composition alone is insufficient: H=l²(N), A=I, e1 fixed, P_n first n modes. <e1,P_n e1>=1 for n>=1 but tr(P_n)=n. Reflected vector sum over n basis pairs has norm sqrt(n), so not a fixed normalizable vector as n grows. Strong convergence P_n -> I is not trace convergence. No claim this example satisfies all gravitational axioms.
2. Replica witness. For positive finite compression A_P <= I, Z_P=tr A_P>0 and integer k>1, tr(A_P^k)/Z_P^k <= Z_P^(1-k). A uniform positive lower bound r over a cofinal exhausting net yields tr A <= r^(-1/(k-1)); if A>=m I then dim H <= r^(-1/(k-1))/m. Identity example has ratio n^(1-k), so finite positive ratios at each cutoff do not suffice. This is the elementary mechanism of (D.47), not a new gravity theorem.
3. Spectral observability. Boost generated by bounded S, U=exp(i t S). For unit vector psi supported in interval centered at s0 with radius delta, ||(U-exp(i t s0))psi|| <= |t| delta. A bounded effect O then changes expectation by at most 2||O|| |t| delta. Mixed/purified version uses the weighted second moment. Distinguishability certifies spectral spread only in the tested state; does not bound global dimension without cofinal uniformity/trace control. Compare (5.32).
4. Noncommuting limits negative control (illustrative, not paper's amplitude): sum_{n>=1} g/[n(1+gn)] is finite for g>0, while the termwise derivative at g=0 is harmonic. Tail <= 1/N for fixed g and partial sum cutoff N. Preserve regulator, topology, order of limits and a dominating bound.
