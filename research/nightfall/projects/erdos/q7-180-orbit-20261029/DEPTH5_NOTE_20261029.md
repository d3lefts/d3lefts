# RYEV / Q7 five-deletion obstruction, 180 published 304-edge representatives

**Status:** exact finite catalogue-local computation, verified in GitHub Actions; external human mathematical review and dated novelty assessment pending. **No 305-edge construction and no global bound on f(7).**

## Statement

Let S be any of the **180 supplied canonical 304-edge C4-free Q7 graphs** in `canonical_180.txt`, as released by Minamo Minamoto and re-audited in the parent PR #63. For any D subset S with |D| ≤ 5, there are **fewer than six** edges e in E(Q7)\\S individually insertable into S\\D without creating a four-cycle.

In particular, deletion of **exactly five** selected edges cannot be followed by the six new additions required to surpass 304 edges. Combined with the previous exact |D|≤4 exclusion, no C4-free Q7 graph of size ≥305 lies within **12 or fewer edge-coordinate changes** from any of these representatives, including their images under cube automorphisms. The minimum possible distance is ≥13.

The conclusion is deliberately *not* a classification of all Q7 C4-free graphs or all 304-edge solutions. The upstream census contains 19,866 released labelled 304-edge solutions grouped into 180 automorphism orbits; other 304-edge solutions may exist outside that census.

## Proof reduction

For a missing edge e, consider each coordinate square C that contains e and exactly three edges of S. The other three selected edges of C form a **tight blocker triple** B(e,C). In any C4-free graph obtained from S by deleting D and adding e, the deletion set D must hit every tight blocker.

For two absent edges e,f, the question whether a size-≤5 deletion set hits all their blockers is a finite **3-element hitting-set decision**. The independent checker recursively branches on all three possibilities for the first uncovered blocker, uses a safe pairwise-disjoint triple lower bound, and memoizes failures. Every branch is justified by the fact that any transversal must contain one of those three elements. Thus a false answer is an exact finite exclusion, not an optimizer timeout.

Construct a graph P5 whose vertices are the absent edges that have ≤5 blockers, joining e,f precisely when the combined blocker families admit a size-≤5 transversal. If **six** absent edges could become individually insertable after the same five deletions, all their pairs would be P5-adjacent: they would form a K6. Enumerate all K6 in P5, then independently solve the *combined* blocker hitting-set problem on all six vertices. Any successful joint transversal is also checked against all 672 coordinate squares after inserting the six edges.

The script independently reconstructs all cube edges/squares in **vertex-major** order, translating the upstream **direction-major** bit masks through an explicit permutation. It checks the C4 property using both coordinate-square occupancy and two-step common-neighbor counts, providing an independent representation from the input encoding.

The latest CI also tests the optimized exact transversal routine against a brute-force powerset oracle on thousands of seeded small-universe instances; the K-clique generator against exhaustive tuple enumeration; and rejects a deliberately corrupted 304-edge witness that preserves its edge count while introducing a square with four edges.

## Reproduce

Run from the repository root on this PR branch (requires Python 3 standard library only):

```bash
python3 research/nightfall/projects/erdos/q7-180-orbit-20261029/check.py
python3 research/nightfall/projects/erdos/q7-180-orbit-20261029/test_depth5.py
python3 research/nightfall/projects/erdos/q7-180-orbit-20261029/depth5.py
```

The theorem checker fails rather than silently certifying a witness if the frozen mask hash changes, if the 128/448/672 geometry changes, if a C4 exists, if any K6 admits a joint transversal, or if the expected 180-mask count changes. Raw logs are archived as a GitHub Actions artifact.
