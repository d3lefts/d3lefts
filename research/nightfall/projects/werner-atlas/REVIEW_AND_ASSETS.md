1. **Lineage reconciliation:** compare the latest approved 4–20 registry with higher archived 6–9 certificate claims under identical physical source scope and margins; independently replay both downstream checker versions.
2. **Upstream premise:** retrieve Tomar's complete posted primary sources and independently reproduce the quantitative `Q_4(4979/10000)≥229/10^7‖C‖_F²` and `Q_5(47/100)≥401/10^5‖C‖_F²` inputs as actually applied to physical, complex rank-two qutrit matrices. Report exact origin, normalization, rounded-error interpretation and independently regenerated SDP data. Treat margins as *premises* until this passes.
3. **Theorem-only certificates:** audit the published three-, four-, five-copy source inequalities and the 19–24 archive's exact independent checker. Confirm every source row, group dimensionality, spectator separability, positive rational weight, strict residual and complete coefficient identity. Separate valid theorem-only transfer from margin-dependent improvements.
4. **Dimension-uniform case:** reread the Costa Rico theorem using trace-difference coefficient `−1/2` rather than the rejected `−1`. Re-run the corrected 8–16 verifier with complex matrices, rank ≤2, all d≥3, and physical copy budget.
5. **Analytic finite-k:** independently rederive the trace-zero projection coercivity lemma, reconstruct `B24_exact.txt`, replay `verify_transfer.py` and test the exact 25-copy symbolic positivity. Establish the precise prior-art boundary.
6. **Restricted compression:** verify `K_j−a_jI∈Sep(A:B)` for the encoded subspace blocks. Keep the 21-copy 13.319× support ratio explicitly distinguished from unrestricted Werner k-copy thresholds.

**Adversarial checks:** reject an entangled maximally-entangled projector used as a *spectator* of a mere rank-two-positive source; reject missing copy-budget accounting, negative exact rational multipliers, falsely rounded SDP slacks, falsely inferred general-dimensional conclusions from qutrit rows, and failed 25-copy floating-point feasibility.

**Publication release gate:** when original JSON/checkers/manuscript archive bytes can be uploaded, record their SHA-256 checksums, publish a GitHub Release or content-addressed assets, independently run the source and downstream verification, and link **only confirmed** public URLs. The repository currently supplies a readable claim ledger, **not** a complete public proof replay. Mathematical novelty and original source inequalities require external specialist scrutiny.
