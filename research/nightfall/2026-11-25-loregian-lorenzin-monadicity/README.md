## Source ledger and dependency map

- Thm 3.1 (recalled): the left adjoint F to U is Pedersen–Baire completion inside the enveloping von Neumann algebra. Thm 3.3 identifies the category of unital monotone sequentially complete C*-algebras and sequentially normal unital *-homomorphisms with the Eilenberg–Moore category of UF. Remark 3.5 extends monadicity to completely positive unital (CPU) maps and the commutative restrictions. Prop 3.8: reflexive coequalizers preserved by monad and cocompleteness.
- Thms 4.2–4.3: separate comonad from adjoint lifting, with sequentially normal CPU maps as coKleisli morphisms; on the stated commutative Pedersen–Baire/Baire-measurable duality the construction recovers Giry probability. Do not conflate this comonad with completion monad.
- Thm 5.3 and Cor 5.4: aleph_1 accessibility/presentability and an essentially algebraic theory of countable arity. This is not finite approximation in norm or a finite algorithmic presentation.
- Thms 6.10, 6.13 and Prop 6.16: symmetric monoidal extension of maximal C*-tensor product with universal property for separately sequentially normal CPU maps. Not a claim that maximal and spatial/minimal norms agree in arbitrary systems.
- Def 7.1, Thm 7.6 and Prop 7.7: a normalized, countably additive instrument p on Boolean sigma-algebra Sigma valued in sequentially normal CP maps A -> B corresponds uniquely to a sequentially normal CPU map L_abs^infty(Sigma) box A -> B, with p(E)(a)=Phi(1_E tensor a). Composition of two instruments is induced by composing the corresponding tensor maps. No extra normal-extension hypothesis in this category; authors explicitly disclaim realization by physical measuring processes and flag an absent sigma-C* version of Stinespring dilation. See §7 before Thm 7.6.
- Proof mechanism worth reuse: extend on simple functions, check positivity after matrix amplification, then prove separate sequential normality using domination 0 <= Phi(f tensor a_n) <= ||f|| p(top)(a_n) for positive f and a_n decreasing to zero. This is a reusable order-continuity argument, not a new result of ours.

## First transfer: retain unnormalized instrument branches before taking probabilities
Objective: source-exact adaptive-instrument acceptance model for Route 1, initially finite-dimensional, finite outcomes and classical finite-coordinate inputs. Feasible set: input-independent CP instrument maps, initial density independent of x, standard one-coordinate controlled query oracle O_x = sum_i P_i tensor U_i(x_i) with orthogonal address projectors and unitary responses (including optional no-query identity sector). Each finite history uses at most T oracle calls; branch choice depends only on already recorded outcomes. Target event is fixed and terminal effects are input independent. Count actual calls along each branch, not expected calls or number of outcomes. Strongest internal comparison: #970/#1042. Gap: check current native circuit interface, formal bridge, and same-scope priority. No assumption that arbitrary CP maps are available for free in a specific physical oracle.

Elementary candidate derivation: write each unnormalized history state as rho_h(x). Fixed linear CP maps preserve the span of matrix-valued functions each supported on at most d coordinate variables. Applying O_x rho_h(x) O_x^* expands into address pairs i,j and adds at most two variables, so after t calls the support-degree is <= 2t. A fixed effect trace preserves degree; summing terminal histories gives scalar f in [0,1] of interaction degree <=2T by normalization of the instrument tree. Thus finite Route 1 can be applied to this acceptance function with its original classical distribution and query cost only after the oracle and target are aligned. This is a proposed elementary composition proof, not an established novel result or a certified terminal. Do not normalize each branch by its probability during the degree argument: that introduces rational functions. This argument does not handle unbounded stopping, arbitrary quantum input sources or infinite outcome spaces.

Minimal adversarial fixture: two binary-outcome instruments on a qubit, each branch has Kraus I/sqrt(2) in instrument A and X/sqrt(2) in B (X is the Pauli flip). Both have effects I/2 for each label, so first outcome distributions agree for all states. On input |0>, final computational-basis measurement gives 0 with probability one for A and 1 with probability one for B. Therefore POVM-only reduction is not semantics-preserving for sequential tasks. Exact branch density matrices are diag(1/2,0) and diag(0,1/2); no floating-point ambiguity. This is a standard elementary counterexample, not source theorem novelty.

Cheapest next decisive test: freeze native oracle definition; compare finite unnormalized branch expansion against direct exhaustive exact rational (or Gaussian rational) matrix evolution for two calls, binary/heterogeneous inputs, measurement, feedback, null branches, early stop, noncommuting terminal effects. Check probability normalization, original-coordinate mixed differences of order 2T+1, and query count. Separate reviewer should derive the degree induction before reading author-side proof, test instrument dependence on x and input-dependent initial state as invalid controls. Budget first pass: n<=5, T<=2, exact matrix fixtures; stop on mismatch or any semantic oracle discrepancy. Significance gate: prove a genuinely broader valid interface beyond existing circuit results, not merely a restatement; novelty requires dated external comparison including instrument/query-complexity antecedents. ### Paper-level proposition and proof
Let X be a classical finite product alphabet. A finite instrument tree has fixed input-independent initial density of trace one, finitely many Kraus operators per outcome, and at most T uses of the controlled oracle O_x = sum_i P_i tensor U_i(x_i) per root-leaf path. Allow fixed CP instrument nodes, with sum of outcome maps trace preserving, and finite terminal effects 0 <= E_h <= I. Address projectors are orthogonal and sum to I; each response is unitary. The decision f(x) is the sum over terminal histories h of Tr(E_h rho_h(x)), where rho_h is unnormalized. For an instrument with multiple Kraus operators use a finite sum of conjugations. Define V_d as the vector space of matrix-valued sums of functions each depending on <= d coordinates. V_d is closed under fixed linear maps. An oracle conjugation is the finite sum over i,j of (P_i tensor U_i(x_i)) rho (P_j tensor U_j(x_j))^*, so sends V_d into V_(d+2). Induction gives rho_h in V_(2t_h), where t_h is the query count on that branch. Since all terminal traces are nonnegative and their sum with E_h replaced by I is exactly one by the trace-preserving tree, f lies in [0,1] and has interaction degree <= 2T. For T=0 it is constant. For T>=1 apply existing finite general-latent Route 1 (#970) directly to the scalar f, with the same input law, actual original-coordinate queries and degree 2T. Heterogeneous finite alphabets can be injected into one finite common alphabet with the input law supported on valid symbols, and extend each U_i arbitrarily unitarily to invalid symbols; no claim that such an encoding supplies a particular physical response oracle. This is paper-level author-side proof, not a new kernel terminal or independent theorem review.

### Critical non-novelty / equivalence gate
For the standard finite additive group translation response oracle, the model is not more powerful in query count than ordinary fixed-depth circuits: purify the input-independent initial state; replace each instrument by the isometry v -> sum_(h,k) |h,k> K_(h,k) v, which preserves norm because sum K^*K=I. Extend each isometry to a unitary on a sufficiently enlarged finite workspace. Retain records orthogonally and control subsequent fixed gates on them. Organize by query count, combining all finite input-independent operations between successive query layers. In a stopped branch, coherently swap the active oracle register with a fresh fixed-address register carrying the uniform response state |+_G> (invariant under every group translation), apply the single common oracle, then undo the swap; this preserves the entire inactive branch without needing controlled black-box access. T global oracle layers suffice. The final effect can be implemented as a binary Naimark isometry v -> |1> sqrt(E_h) v + |0> sqrt(I-E_h) v controlled on h, extended to a unitary and measured in the output basis. Preparatory fixed gates can be absorbed into the starting state; all other fixed operations between queries can be combined. This is a standard deferred-measurement/dilation construction with an explicit harmless-query padding argument. It gives a source-level route to the older circuit model, not a query advantage or proof of novelty. For arbitrary controlled unitaries with no common invariant padding state the fixed-depth compilation needs separate justification; the direct degree induction does not. No assertion about countable outcome dilation, actual destructive sensors, unbounded expected stopping, or runtime/ancilla cost.
