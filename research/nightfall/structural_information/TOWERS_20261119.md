# Towers: rank-one settled, and the decisive test case for Conjecture E (2026-11-19)

Status: Proposition G proved on paper; the tower claim is sketched; Section 3 identifies a family that
will either refute Conjecture E in its frame form or force a non-frame simulation. Not reviewed.

## 1. Rank-one rows (Proposition G, proved)

Rows `x yᵀ` (`x, y ∈ F_2^a ∖ 0`) acting on `S ∈ F_2^{a×a}`: the input is the truth table of the bilinear
form `(x, y) ↦ xᵀ S y`; `m = a²`.

* **Advantage.** `r·R` is the set of matrices of rank `≤ r`; Flanders' theorem gives `N_r = r a`, so by
  Theorem C an `r`-query algorithm computes a function needing `≥ r a / 2 − O(1)` classical queries.
* **Simulation.** The rows include every entry `e_i e_jᵀ`, so a classical algorithm reads `S` with
  `m = a²` queries: cost `≤ a² ≤ N_1²`.

So Conjecture E holds for rank-one rows with exponent 2. **Tower view:** for fixed `x` the block
`{x yᵀ : y}` is Bernstein–Vazirani on `u_x = Sᵀx` (balanced, rank `a`); merging each block gives
vector symbols `σ_x = Sᵀx`, which form a Bernstein–Vazirani code over the alphabet `F_2^a` (balanced,
rank `a` in symbols); merging again gives `S`. Two levels of rank `a` each: cost `a · a`.
Whether the true simulation cost is `a · poly(T)` (matching `N`) is open.

## 2. Bounded-depth towers (claim, proof sketch)

A **tower of depth `D`** is a chain of representations in which each level's coordinates are
vector-valued linear functions of `s` that split into balanced blocks (Theorem F's setting, with
vector alphabets), and level `ℓ + 1` consists of the merged symbols of level `ℓ`. Theorem F applied
level by level (it needs only the alphabet-free product theorem, which holds for vector alphabets)
should give simulation cost `∏_ℓ k*_ℓ · poly(T)` and advantage `max_ℓ k*_ℓ`, hence
`Λ ≤ N^D`: Conjecture E holds with exponent `D` for bounded depth. The vector-alphabet version of
Theorem F's proof is the step to write out.

## 3. The decisive case: unbounded depth (subcube parities)

Take `L`-fold rank-one tensors over `F_2^2`: rows `x_1 ⊗ ⋯ ⊗ x_L` with `x_i ∈ F_2^2 ∖ 0`, acting on
`S ∈ (F_2^2)^{⊗L} ≅` functions `{0,1}^L → F_2`. Each row is the **parity of `S` over a subcube** of
`{0,1}^L`; `m = 2^L`, `n = 3^L`.

* **Small subspace number (proved).** `|r·R| ≤ 3^{Lr}`, and a `k`-dimensional subspace inside `r·R`
  needs `2^k ≤ |r·R|`, so `N_r ≤ (log₂ 3) · L · r = O(r log m)`. Conjecture E therefore predicts
  simulation cost `poly(T, log m)`.
* **No cheap frame of product form.** In any basis of `F_2^2`, exactly one of the three nonzero
  vectors has weight 2, so per-coordinate bases give some rows weight `2^L = m`. The natural tower has
  depth `L = log m` with rank 2 per level, and merging costs `2^L = m`. Short dependencies are
  everywhere (a cube is the sum of its two halves: weight 3).
* **Heuristic evidence against an advantage.** One query returns a state in a `3^L`-dimensional
  space, so at most `L log₂ 3` bits about `S` per query (Holevo). Natural global statistics, such as
  the average subcube bias, concentrate at `≈ 0` for random `S`.

So this family is decisive:

1. If a classical simulation with cost `poly(T, log m)` exists, it cannot be a frame or a tower
   merge. Conjecture E's frame formulation is then too narrow, though the characterization by `N` may
   survive with a different simulation argument.
2. If some `poly(L)`-query quantum algorithm needs `2^{Ω(L)}` classical queries, the subspace number
   does not characterize advantage. The right measure would then have to be **recursive**, as in
   Bernstein–Vazirani's recursive Fourier sampling, which builds superpolynomial separations from
   towers of BV instances.

Either outcome is a substantive result. Deciding it is the next target.
