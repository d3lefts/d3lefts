# Towers: rank-one settled, and the decisive test case for Conjecture E (2026-11-19)

Status (2026-11-19 correction): Proposition G is author-side; the bounded-depth tower claim is sketched. **Section 3's tensor-subcube family refutes Conjecture E's unrestricted FRAME formulation** via a new author-side proof in [SUBCUBE_FRAME_REFUTATION_20261119.md](SUBCUBE_FRAME_REFUTATION_20261119.md). Its actual quantum/classical query-complexity behavior remains open. Not Lean certified or independent human reviewed.

## 1. Rank-one rows (Proposition G, proved)

Rows `x yᵀ` (`x, y ∈ F_2^a ∖ 0`) acting on `S ∈ F_2^{a×a}`: the input is the truth table of the bilinear
form `(x, y) ↦ xᵀ S y`; `m = a²`.

* **Advantage.** `r·R` is the set of matrices of rank `≤ r`; Flanders' theorem gives `N_r = r a`, so by
  Theorem C an `r`-query algorithm computes a function needing `≥ r a / 2 − O(1)` classical queries.
* **Simulation.** The rows include every entry `e_i e_jᵀ`, so a classical algorithm reads `S` with
  `m = a²` queries: cost `≤ a² ≤ N_1²`.

So Conjecture E holds for rank-one rows with exponent 2. **Tower view:** for fixed `x` the block
`{x yᵀ : y}` is Bernstein–Vazirani on `u_x = Sᵀx` (balanced, rank `a`); merging each block gives
vector symbols `σ_x = Sᵀx`, which form a Bernstein–Vazirani code over the alphabet `F_2^a` (balanced,
rank `a` in symbols); merging again gives `S`. Two levels of rank `a` each: cost `a · a`.
Whether the true simulation cost is `a · poly(T)` (matching `N`) is open.

## 2. Bounded-depth towers (claim, proof sketch)

A **tower of depth `D`** is a chain of representations in which each level's coordinates are
vector-valued linear functions of `s` that split into balanced blocks (Theorem F's setting, with
vector alphabets), and level `ℓ + 1` consists of the merged symbols of level `ℓ`. Theorem F applied
level by level (it needs only the alphabet-free product theorem, which holds for vector alphabets)
should give simulation cost `∏_ℓ k*_ℓ · poly(T)` and advantage `max_ℓ k*_ℓ`, hence
`Λ ≤ N^D`: Conjecture E holds with exponent `D` for bounded depth. The vector-alphabet version of
Theorem F's proof is the step to write out.

## 3. Unbounded-depth subcube parities: frame obstruction proved, task complexity open

Take `L`-fold rank-one tensors over `F_2^2`: rows `x_1 ⊗ ⋯ ⊗ x_L` with `x_i ∈ F_2^2 ∖ 0`, acting on
`S ∈ (F_2^2)^{⊗L} ≅` functions `{0,1}^L → F_2`. Each row is the **parity of `S` over a subcube** of
`{0,1}^L`; `m = 2^L`, `n = 3^L`.

* **Small subspace number (proved, with corrected at-most-r count).** Because the sums can use *at most* \(r\) rows, \(|r\cdot R|\le(3^L+1)^r\), not \(3^{Lr}\) (the latter fails for \(r=1\) because \(0\) is included). Thus \(N_r\le r\log_2(3^L+1)=O(rL)\) and for fixed r this is logarithmic in \(m=2^L\).
* **All high-girth frames are expensive (proved author-side, not merely product-form frames).** Every \((c,c',h)\)-frame with \(h\ge3c\) satisfies \(cc'\ge c\ge (4/3)^L\). The proof uses local three-term tensor relations generating the whole relation kernel and the exact \(2^L\) minimum distance of the tensor \([3,2,2]\) simplex evaluation code. The source smoothing threshold satisfies the girth premise. The standard tensor-coordinate basis provides the coarse upper bound \(cc'\le 2^L\). Full proof and checker: [SUBCUBE_FRAME_REFUTATION_20261119.md](SUBCUBE_FRAME_REFUTATION_20261119.md).

* **Heuristic evidence against an advantage.** One query returns a state in a `3^L`-dimensional
  space, so at most `L log₂ 3` bits about `S` per query (Holevo). Natural global statistics, such as
  the average subcube bias, concentrate at `≈ 0` for random `S`.

**The frame question is now settled negatively.** The all-frame exponential lower bound refutes Conjecture E as stated, regardless of whether the distribution permits an efficient non-frame classical simulation. The two remaining TASK alternatives are (i) a non-frame classical simulator of cost polynomial in `T,L`, or (ii) a polynomial-in-`L`-query quantum acceptance observable with exponential-in-`L` classical row-query complexity. Neither alternative has been proved by this frame obstruction. A quantum recursive-Fourier-sampling analogy alone is not evidence of a matching oracle/source embedding.
