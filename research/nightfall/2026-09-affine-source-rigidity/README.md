For the shifted prime-difference series
```
A⁺(s) = Σ_p [(p−1)^(−s) − p^(−s)],
```
the manuscript derives the absolutely convergent expansion in Re(s)>0,
```
A⁺(s) = Σ_{k≥1} (s)_k P(s+k)/k!,
```
where P is the prime-zeta series.

For nontrivial zeros ρ,ρ' of ζ, the affine source Φ(ρ,n,k)=ρ/n−k satisfies
```
Φ(ρ,n,k)=Φ(ρ',n',k') iff k=k' and n'ρ=nρ'.
```
The argument uses the location 0<Re(ρ),Re(ρ')<1 to force agreement of integer translation layers, then equates the two rationally scaled zeros. The rational-dilation fibers are finite. The paper also isolates the first shifted prime-zeta layer as A⁺(s)=sP(s+1)+H(s), H holomorphic on Re(s)>−1, with the normal local-branch qualifications.

The companion *Arithmetic Singularity Transfer* treats the related un-subtracted prime shift and principal-layer singularities **under an explicit RH hypothesis and local branch assumptions**. This is a conditional structural continuation statement; it establishes no proof of RH.
