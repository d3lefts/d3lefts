## 1. Exact feasibility and minimum dimension

Let B:X→U (donor observation), C:V→Y (recipient task decoder), F:X→Y (required task) be linear. An arbitrary map g:U→V can satisfy Cg(Bx)=Fx for all x iff ker B⊆ker F and im F⊆im C. Necessity: compare x in ker B with 0; every output lies in im C. Sufficiency: P=CC† (orthogonal projector onto im C), Q=B†B (projector onto (ker B)⊥), and T=C†FB† gives CTB=PFQ=F. Here † is Moore–Penrose inverse.

rank T≥rank F for every exact linear transfer; the construction attains rank F by rank(product)≤rank F. It also minimizes operator norm among exact linear transfers: for any exact T, C†CTBB†=C†FB† is the orthogonal output/input compression of T, hence norm no larger. No nonlinear exact map can avoid the two obstructions. Rank measures linear dimension, not bits, coordinate recovery or computational cost.

## 2. Sharp minimax error including nonlinear transfers

Define E(g)=sup_{||x||≤1}||F x-Cg(Bx)||. Then

inf_g E(g) = min_T ||F-CTB|| = max{||(I-P)F||, ||F(I-Q)||} = t.

All norms here are Euclidean induced operator norms. Lower bound for any g: (i) orthogonal projection onto (im C)⊥ gives error ≥||(I-P)F||; (ii) for unit x∈ker B, g receives identical observation 0 on x,-x, so the triangle inequality gives max errors ≥||Fx||. Sup over that subspace gives ||F(I-Q)||, including the zero-dimensional case. Same lower bound for randomized transfer under worst-case expected Euclidean loss, by expectation of the two-point inequality. Upper bound attained deterministically.

Proof of upper bound, including rectangular or singular blocks: split X=ran Q ⊕ ker Q and Y=ran P ⊕ ker P; F has blocks [A E; G D]. The upper-left block of F-CTB is freely selectable, because any M supported on ran Q→ran P can be realized by T=C†MB†. The lower row [G D] and right column [E;D] have norms ≤t. If t=0 take residual zero. Otherwise divide all three fixed blocks by t; use e,g,d for normalized E,G,D. Define Δ=(I-d* d)^(1/2) and Γ=(I-dd*)^(1/2). From e*e≤Δ² and gg*≤Γ², obtain contractions K=eΔ† and L=Γ†g, with e=KΔ and g=ΓL. E.g. e vanishes on ker Δ by inequality; for u in ran Δ, ||eΔ†u||≤||u||, and it vanishes on ker Δ. The L argument is the adjoint version. The block operator J=[-d* Δ; Γ d] maps (target-forbidden ⊕ source-hidden) to (source-hidden ⊕ target-forbidden); J*J=I and JJ*=I via dΔ=Γd (SVD). Then diag(K,I) J diag(L,I)=[-K d* L e; g d] is a contraction. Multiply by t. Choose its upper-left block as residual R11 and transfer T=C†(F-R)B†. F-R is supported exactly on allowed block. This is the Parrott completion argument; proves equality, not merely an upper estimate.

Consequences: linear transfer is minimax-optimal even among nonlinear maps under this precise Euclidean model. Failure to achieve t with a learned linear map is optimization error or additional constraints, not an inherent advantage of nonlinear transfer. This statement does not apply to arbitrary nonlinear F/B/C, arbitrary input set, classification accuracy, per-layer neural constraints or bounded map rank/norm.

Strict baseline counterexample: B=[1 0], C=[1;0], F=[0 1;1 1]. The canonical least-squares choice T=0 has operator error (1+sqrt(5))/2; choose T=1 giving residual [-1 1;1 1], with R*R=2I, exact minimax sqrt(2). Source blindness and recipient unrealizability each equal sqrt(2), so no nonlinear g improves it. More generally for scalar missing block x and fixed b,c,d, t²=d²+max(b²,c²), choose x=-bdc/(t²-d²) if denominator positive, otherwise x=0. This is exact rational when b,c,d rational.

## 3. Compression and noise
For rank(T)≤k, the exact minimum squared Frobenius error is
||F-PFQ||_F² + sum_{i>k} σ_i(PFQ)².
Orthogonal block decomposition gives ||F-CTB||_F²=||F-PFQ||_F²+||PFQ-CTB||_F². The reachable rank≤k matrices are precisely the rank≤k matrices supported on ran Q→ran P, by pseudoinverse construction. Truncated SVD gives equality. For isotropic x with E[xx*]=I (second moment, not necessarily centered), this is the minimum expected squared task error among linear rank≤k maps. For x with second moment I/d divide by d. Does not claim rank-constrained spectral optimum or nonlinear low-dimensional encoding optimality.

Separate sharp additive-noise result: y=Bx+e, ||e||≤δ, x ranges over all X. If exact feasibility fails, minimax error is infinite (scale either obstruction). If feasible, inf_g sup_{x,e}||Fx-Cg(y)|| = δ||F B†||. Upper: use T=C†FB†; lower: choose e with ||e||≤δ in im B, x=±B†e, noises ∓e, same y=0, use two-point inequality. FB† annihilates (im B)⊥, so this realizes operator norm. δ=0 included. Restricting x to a ball may lower the bound; joint bounded-state/bounded-noise minimax is a separate open scope here.

## 4. Continuation-closed observability

Source initial x∈X (dim n), recipient initial z=T B x∈V (dim m). Desired output after finite common word w over alphabet Σ is F0 A_w x; actual output C0 D_w z. A_a and D_a are fixed linear updates on X,V. Products ordered so every word corresponds to sequential composition; empty word identity. Matching today is not matching after future operations.

Define joint state v=(x,z), joint update M_a=diag(A_a,D_a), and output L=[F0,-C0]. Start W0=row L. Iterate W_{h+1}=W_h+sum_a W_h M_a. Then W_h spans the rows of L M_w for |w|≤h by induction. If W_{h+1}=W_h, closure under each M_a makes all later spaces equal. Dimension grows at each nonstationary step; with N=n+m and r0=rank L>0, stabilization by H=N-r0≤N-1. If L=0 trivial. Therefore exact task agreement for all words is equivalent to agreement for a finite spanning row basis at depth ≤H. It is unnecessary to enumerate exponentially many words: expand only an independent row basis and retain each new row's generating word; at most N basis rows, polynomial field operations for fixed matrix inputs (bit complexity depends on arithmetic). Kernel of W is the largest common invariant subspace contained in ker L: every invariant subspace there annihilates all L M_w; conversely W invariance makes ker W invariant.

Take R a full-row-rank matrix whose rows form a basis of W, partition R=[R_s,R_t]. Then exact all-word transfer iff R_s+R_t T B=0. Apply §1 to F=R_s,C=-R_t. Feasible iff ker B⊆ker R_s and im R_s⊆im R_t; minimum rank T=rank R_s. This equals rank of the source-only continuation signature stacked through H: row operations on joint signatures preserve each column restriction's row span. Rank bound is invariant under choice of basis. For exact arithmetic take rational or finite field row basis; do not require orthonormality for exact closure. Immediate task failure witness can be deferred to length N-1 in general: L=e1*, M with superdiagonal ones, v=eN gives outputs zero until length N-1. For an explicit 2D delayed mismatch, L=[1,0], swap coordinates, v=e2. This is the obstruction to preserving only a single observer. Not a new weighted-automata equivalence theorem.

## 5. Robust all-continuation guarantee

Take R with orthonormal rows spanning W in the Euclidean joint state space. By closure R M_a=K_a R with K_a=R M_a R*, and L=H0 R with H0=L R*. Thus for any x,z and any word w=a1,...,ak,
||F0 A_w x-C0 D_w z|| ≤ ||H0|| (prod_i ||K_ai||) ||R_s x+R_t z||.
The exact equality before norm is H0 K_w (R_s x+R_t z). Choose T by the two-sided minimax construction with F=R_s,C=-R_t. For ||x||≤1 define t*=max(||(I-P_t)R_s||,||R_s(I-Q)||), P_t projector onto im R_t. Then all words of length k have output error ≤||H0|| γ^k t*, if every ||K_a||≤γ. If γ≤1, uniform all-horizon certificate; if γ>1, no uniform claim. More generally any certified bounds on products can replace γ^k, including alternate common quotient norms if the residual measured in that norm is bounded accordingly. These are guarantees, not claims of minimax for sup_w actual output error (minimax is for Euclidean signature residual). The source/recipient may have arbitrarily unstable unobservable modes; only induced observable dynamics matter.

No full-space contraction requirement. Example M=diag(1/2,2), L=(1,0), W=span e1, K=1/2. Hidden coordinate doubles, observable perturbation shrinks. Conversely M=diag(2,1/2), same L, initial observable error ε grows 2^k ε. Exact closure at finite H does not justify uniform approximate continuation without a stability certificate.

Practical certificate: R with RR*=I, L=H0R, R M_a=K_aR, PSD tests γ²I-K_a*K_a⪰0 and t²I-(R_s+R_tTB)*(R_s+R_tTB)⪰0. For rational nonorthonormal basis use positive definite metric and congruence-weighted inequalities; verify via exact rational LDL/principal minors or interval enclosures. Use known matrices to construct certificate; learning those matrices from finite neural data is not covered. For logits, if baseline margin m>2δ and score ∞-error ≤δ, unique top class preserved. Euclidean output error bounds imply ∞-error bound, but not arbitrary accuracy rates.
