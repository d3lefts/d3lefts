**Research status must be read claim by claim.** Exact finite numerical verification, conditional deductions from imported external source theorems, manuscript proofs, software experiments, and conjectural approaches carry different evidentiary weights. The Erdős continuous-shift certificate is source-reported as independently implemented and internally replayed. It has yet to pass full external specialist review. The Werner higher-copy results retain explicit quantitative source assumptions. No global critical-line proof is claimed.

The 131,072-cell exact mathematical witness is separate from a rejected oversized Arena entry and from an accepted leaderboard entry whose exact source file is still being recovered. See [witness identity and prior-art ledger](https://github.com/d3lefts/d3lefts/blob/main/research/nightfall/projects/erdos/STATUS_AND_PRIOR_ART_20261028.md).

Reproducing mathematical claims requires reading the full primary source inputs and checker assumptions, not merely matching a displayed decimal.
