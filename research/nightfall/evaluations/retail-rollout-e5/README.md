# Retail rollout calibration

Give the solver only [the candidate directory](candidate/ISSUE.md). From this directory run `python check.py candidate` on the trusted public starter. Each of the five groups prints pass or fail and is worth 20 points. An unexpected exception invalidates the run. Inspect the five outcomes for the score.

In local author calibration the starter passed its one smoke test and scored 0/100. A repair developed in the same session scored 100/100. The checker is public and checks selected histories. It does not measure blind model performance or audit installation cost. Before using a new private variant for model evaluation, freeze the prompt, scorer, attempt budget and independently reviewed alternate repair. Preserve failed attempts and use an isolated grading process. The legacy dashboard's partial state describes the currently known fulfillments, so registering a pending part can legitimately change a previously shipped order to partial.
