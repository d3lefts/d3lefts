# NIGHTFALL / CONSTELLATION — Joined Source-Bound Investigation

**Dated 29 October 2026 · development evidence gate · human-run**

## Scientific target

The already source-linked, genuinely unresolved Frontier task NF-156-184-9 asks whether the interval [1,184] contains a **maximal classical Sidon set of nine integers**. The exact positive closure requires nine distinct marks, 45 unique unordered pair sums including the diagonal, and rejection of every one-mark insertion among the other 175 positions. A *global negative* result requires an exhaustive independently checkable proof of nonexistence across all nine-element choices. Failed local candidates, even many of them, never settle the global question.

The previous contributor interface checked a finite candidate and required a person to copy the result into notes. Its "Challenge" stage opened a generic independent-lane planner, with no source-specific finite attack or machine-checkable receipt. This upgrade keeps one real question and all user-triggered work in the Join workspace.

## Implemented route

1. **Human selects a frozen branch** from existing Frontier source. Its complete canonical packet, including source version and exact minimum-mark interval, is reconstructed and validated on every calculation.
2. **Human runs one finite candidate check.** The existing Frontier checker calculates pair-sum uniqueness and tests all omitted insertions. A second, independent algorithm checks positive-difference uniqueness (the classical Sidon equivalence) and separately derives extendability using one frozen old pair-sum table and all candidate insertions. Agreement is required; the methods are independent algorithm paths in the same browser, not an external reproduction.
3. **Human challenges this exact input.** Three negative controls must be rejected for the expected reasons: duplicated coordinate, additive collision, and an actual strong Sidon candidate with an allowed insertion. The attack also records the concrete reason the user's candidate fails, if any. An inconclusive attack blocks saving a scoped receipt.
4. **Human explicitly preserves the finite evidence.** A canonical versioned object records the frozen assignment, exact nine marks, both arithmetic outcomes, negative controls, user-authored text, and unreviewed status. Up to twelve source-bound records remain in local browser storage and can be exported as a single reproducible JSON packet. User notes are user-authored, not identity-authenticated.
5. **Local replay refuses altered scientific fields.** Loading the ledger revalidates the frozen Frontier contract, recomputes the finite result and negative controls, and rejects any changed finite output, modified branch, promoted proof status, or oversized ledger. Edits to the user's own untrusted prose are not cryptographically attestable. There is no signed server record.
6. **Other instruments stay available.** The frame/explore paths continue using frozen one-shot handoffs. Claim Lab receives an *unreviewed assignment input*, not a fabricated published claim or certificate. Q7 remains on Orchestrator/source-checker routes because the Join page has no global Q7 oracle.

## Frozen acceptance and matched-budget evaluation

The unit and browser tests are an engineering acceptance pilot, *not* a scientific productivity result. For exactly three finite N=184 candidate inputs, the two local arithmetic implementations must agree and classify all outcomes: invalid repeated coordinates, additive pair-sum collision, and valid but extendable nine-mark set. The live visitor test must preserve a rejected candidate as evidence, export a valid receipt, survive reload, then refuse a modified verdict; its stage transitions must carry one consistent branch and never silently promote review status. These are deterministic fixed cases; they provide 0 claims of increased real-world discovery yield.

## Important limitations

- No additional agent, background execution, scheduled run, or automatic publication authority is introduced.
