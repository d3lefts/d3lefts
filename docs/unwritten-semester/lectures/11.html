SESSION 11 / 14 — VERIFY

Causality, observability & impossible knowledge

Detect observationally indistinguishable worlds before optimizing.

90 min · lab 3hLECTURE + LAB + ADVERSARIAL CHECKNO PREREQUISITE INSTALLS

The operating principle

A measurement system may have many sensors and still be unable to distinguish two decision-relevant worlds. Observability is about recovering information from available measurements; identifiability is about distinguishing models or parameters; causal inference is about what would happen under an intervention. These questions are connected but not interchangeable.

A perfect predictor can rely on a spurious variable. A calibrated sensor can be useless for the decision if the uncertainty it resolves never changes the action. An observability matrix can have full rank in a linear model that fails under an unmodeled change.

A two-world impossibility argument

Suppose safe world W0 and unsafe world W1 produce exactly the same observable input o to any admission rule. A deterministic rule must return the same action in both worlds. Therefore it cannot both admit W0 and reject W1 based on o alone. A randomized rule cannot have both probabilities equal to one for the opposite required actions either.

This is a basic indistinguishability argument: it identifies missing evidence. It does not show that all useful admission rules are impossible; it states what cannot be guaranteed under that observation map.

Lab — find indistinguishable worlds

  1. Describe two states in AURORA that produce the same sensor reading but imply different true event status.
  2. Write a causal graph with event, common outage, available channels, readings, alarm, and human action.
  3. Name which arrows are implemented by the simulator and which are unmodeled assumptions.
  4. Formulate an additional observation that could distinguish the two worlds; estimate its acquisition cost.
  5. Explain whether its acquisition improves state estimation, causal identification, decision value, or more than one.

Acceptance artifact: 11-indistinguishability.md containing a two-world construction and one observation-design proposal.

Adversarial check

Search for model pairs that fit every observed datum but disagree on the intervention outcome. If they exist, report partial identification or additional assumptions; do not fill the gap with a smooth narrative. If an experiment resolves only a model-internal ambiguity, say so.

Doctoral extension

For a linear dynamical system with specified matrices, calculate the observability matrix rank and construct an unobservable state direction if the rank is deficient. Then compare this local algebraic result with a nonlinear or distributional identifiability argument.
