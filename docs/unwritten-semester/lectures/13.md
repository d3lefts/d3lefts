## The operating principle

A paper that cannot be rebuilt from its sources is a fragile scientific artifact. **Reproducibility engineering** means managing source, environments, data, parameters, randomness, compute budgets, derived figures, and citations as a coherent system.

A terminal degree requires a defensible chain from question to data to conclusion. A repository is not that chain by itself. A good research package can answer: which inputs produced this figure; what code and dependencies were used; what changed between versions; how did we detect corruption; and what external assumptions remain unverified?

## The minimal research release

```text
research/
  README.md                  # exact replay and limitations
  claim-ledger.csv           # current and superseded claims
  src/                       # fixed source revision
  data/raw/                  # immutable primary data or source URLs
  data/derived/              # regenerable outputs
  experiments/               # preregistration and run metadata
  evidence/                  # hashes, independent checks, exceptions
  paper/                     # manuscript and figure generation
```

Use recorded commands; document language/runtime version; define units and schemas; prohibit silent manual edits of derived results. A checksum detects accidental or unauthorized changes **relative to a trusted digest**. It does not attest that the original data were accurate.

## Lab — package an inspectable result

1. Run the standard-library simulator with a recorded seed and save the CSV trace.
2. Independently audit it with `labs/audit.py`.
3. Record the SHA-256 of both source and trace (`sha256sum` on Linux; `shasum -a 256` on macOS, or Python `hashlib`).
4. Write a provenance manifest including command, runtime, input parameters, source commit if available, checker output, and limitations.
5. Reproduce the result in a fresh directory. Verify that a one-byte trace mutation is detected by your stored digest.

**Acceptance artifact:** `13-reproducible-release/` with one-command replay, a manifest, a verified trace, and a clear data dictionary.

## Adversarial check

Replay from the README without oral instructions. Check for hidden network access, ambient local files, mutable dependencies, timezone assumptions, platform-specific behavior, and unexplained postprocessing. Independent review is a social and methodological condition, not a property asserted by a script name.

## Doctoral extension

Build a provenance-directed acyclic graph; show how content-addressed storage can make dependency changes inspectable. Specify threat assumptions for stronger authenticated attestations and what a cryptographic signature still cannot verify.
