# The Unwritten Semester — release record

## 1.1 — executable field methods and quantitative bridge

- Preserved all 14 original research-method sessions, original AURORA capstone, and independent attribution to MIT's teaching format.
- Added `toolkit.html`: four reproducible field practicums with positive and negative acceptance criteria.
- Added `math-bridge.html`: exact mathematical micro-exercises and terminal-degree preparation topics (without claiming to replace doctoral technical coursework).
- Added `labs/compare.py`: same-world, paired policy comparison under explicitly stipulated loss/prevalence; stratified paired percentile bootstrap with synthetic-model limitations.
- Added `labs/exact_switch.py`: exact rational event-prevalence crossing for conditional loss curves; reference value `19910/80843` under the declared observed counts and example loss model.
- Added `labs/modelcheck.py`: exhaustive 27-state policy abstraction check, with mutation-detection tests.
- Added `labs/passport.py`: SHA-256 identity manifest and declared transitive change impact; not an authenticated certificate or proof of dependency completeness.
- Added `scripts/check_site.py` and `scripts/verify_reference.py`; repaired and extended receipt source hashes; added a reusable GitHub Actions workflow for standalone repositories.
- Updated references to include NASA's systems modeling and digital engineering guidance.
