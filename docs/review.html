SUBMISSION CONTRACT

A finding counts when it can travel.

Every external review receives a traceable entry. Failed proofs and failed reruns are welcome; they help correct the public record.

  1. Choose a bounded review assignment and read its primary source.
  2. Record your environment, source version, exact file hashes, and reproduction commands.
  3. Submit a concise pass / fail / inconclusive judgment with proof or counterexample.
  4. Propose a report through a GitHub pull request to the research archive; reviewer credit is attributed with consent.
