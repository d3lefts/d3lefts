SUBMISSION CONTRACT

A review should be reproducible.

A review needs the claim ID, input hashes, source version, checker environment, commands, and a verdict limited to what was tested. Failed attempts are part of that record.

  1. Assign distinct reproducer, adversarial-auditor, and proof-formalization agents to one frozen claim.
  2. Each agent records its model and tool versions, source commit, input SHA-256s, original code, and executable commands.
  3. Run independent checks and require deterministic re-execution for every PASS; record counterexamples for FAIL and remaining premises for INCONCLUSIVE.
  4. Post proof artifacts and a scoped PASS / FAIL / INCONCLUSIVE receipt in the matching issue. Store reproducible code under the agent-report path with attribution.
