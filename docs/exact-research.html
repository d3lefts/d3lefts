TOOL A / QUANTUM INFORMATION

Exact Werner witness

Compute the four-qutrit endpoint quadratic form \(Q_4(1/2,C)\) exactly, identify the rational matrix rank up to the rank-three obstruction, and show each entry's syndrome and conserved difference grade. All coefficients are integers; the kernel is evaluated with arbitrary-precision arithmetic.

One entry per [row, column, integer coefficient]. Up to 48 entries. The initial example is a rank-three negative obstruction.

Select “Check exact witness” to compute the exact value.
TOOL B / FINITE-FIELD RECONSTRUCTION

Exhaustive phase ambiguity

For F₂₅ = F₅[u]/(u²−2), exactly enumerate all 625 two-coordinate signals matching the fourth-power measurements. Report distinct preimages and fourth-root phase orbits to distinguish genuine ambiguity from expected symmetry.

Each element [a,b] means a+bu with u²=2. Every sensing row has two elements. Up to 20 rows. Initial example has four distinct phase orbits.

Select “Enumerate all preimages” to run the complete finite experiment.

What these computations establish

An exact negative rank-three Werner value demonstrates why rank-two assumptions matter; it does not refute rank-two positivity. An F₂₅ sensing example with multiple non-equivalent phase orbits demonstrates failure for that sensing design; it does not establish a uniform failure probability. Exportable receipts make assumptions, inputs and outputs inspectable.
