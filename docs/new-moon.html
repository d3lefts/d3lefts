START HERE / ONE FINITE REPLAY

Don't take our word.
Run the check.

Begin with a bounded 30-integer Sidon construction. This verifies a particular finite statement, not a new asymptotic theorem or a novelty claim.

  1. Clone the public repository and keep the original witness file alongside its checker.
  2. From the repository root, execute the published Python 3 standard-library replay:
python3 research/nightfall/projects/sidon-finite-30/verify_sidon30_standalone.py
  1. Expect "status": "PASS" and "exact_sidon_number": 17. A different output is a reason to investigate, not to assume success.
  2. For actual independent criticism, reimplement a mathematical check without copying the supplied algorithm. Rejection of a tampered witness hash alone proves only input identity.
