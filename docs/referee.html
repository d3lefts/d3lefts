INPUT / 01

Integer step-function witness

Paste integer cell heights over [0,2], using denominator D. All heights must satisfy 0 ≤ Aᵢ ≤ D and exact unit mass, 2ΣAᵢ = nD. Accepts 2–256 cells.

FINITE MATHEMATICAL SCOPE

Exact means
exactly specified.

For each signed lag k, we calculate Σ Aᵢ(D − Aᵢ₋ₖ), taking only overlapping indices, with zeros outside the support.

(2 / nD²) · maxₖ C(k)
  • Engine A: signed-lag summation.
  • Engine B: pair-difference accumulation.
  • All 2n − 1 relevant integer lags.
  • Piecewise-linear continuum interpolation.
  • Normalization and tampering controls.

This does not replay NIGHTFALL’s 131,072-cell archived witness. A small fixture is supplied to test this exact finite method.

INPUT / 02

Sidon finite witness

The public 30-point witness is preloaded. We check the (4,5) condition and the weaker weak-Sidon property separately, together with an explicit Sidon subset, and the absence of a larger Sidon subset using an exact progression-hitting search.

FINITE MATHEMATICAL SCOPE

Disprove the
18th element.

Two distinct conditions are checked: (4,5) requires five distinct distances in every four points; weak Sidon forbids equal two-pair sums among four distinct marks. They are not equivalent. We certify the explicit 17-element Sidon subset and search all possible deletions of at most 12 points.

h(B) = 17,   |B| = 30,   h(B)/|B| = 17/30
  • All 27,405 four-point subsets.
  • Definition negative control: {1,2,3,5} is weak Sidon, but fails (4,5).
  • 153 unique Sidon pair sums.
  • Exact three-term progression constraints.
  • Memoized transversal branch-and-bound.
  • Hard search cap → inconclusive, never pass.

This is a finite witness claim, distinct from asymptotic bounds, publication novelty, and external peer review.
