01 / EXACT OPERATOR

Operational quantum ANOVA

COMPLETE ANALYTIC ARGUMENT · FINITE EXACT / COMPLEX TESTS · NOT LEAN CERTIFIED
G*(Q) = Σ∅≠S⊆Q γS   with   γS ≥ 0

For a finite classical–quantum ensemble with unconditional average state B = ⊗ibi, optimizing squared-error prediction of a single real target over all joint POVMs on Q yields a nonnegative interaction expansion. Hence G* is monotone and supermodular: revealing a register can never have a smaller marginal optimal gain after more registers have been acquired.

In the real Hilbert space of Hermitian estimators with Jordan/SLD inner product, state-weighted conditional projections satisfy PAPC = PA∩C. Their commuting Boolean atoms give γS = ‖DSL‖2 ≥ 0. Only the average state must tensorize for this operator argument; conditional signal states need not commute or themselves be product states.

02 / CHARACTERIZATION

When is complementarity universal?

ANALYTIC v3 BRIDGE · EXTERNAL MATHEMATICAL AND PRIORITY AUDIT OPEN

For faithful finite-dimensional average state B, a product structure B = ⊗iBi is equivalent to supermodularity of the optimal scalar Bayes-gain set function for every finite classical–quantum ensemble with average B. The converse can be tested with equiprobable binary perturbations of B.

This is a universal-over-ensembles statement. A particular ensemble can be supermodular with a correlated average state; conversely, it does not assert that correlated inputs always produce informational substitutes. The result generalizes the conditional-expectation geometry behind classical independent-signal complementarity.

Binary contrast removes the extra SLD penalty
