01 / AI SAFETY · SOURCE PROVENANCE

SourceBound

A constrained admission boundary for source-grounded machine-readable assertions.

Implementation + frozen test package
External field evaluation open

Problem and approach

Generated records can silently switch subjects, rely on stale pages, or confuse an assertion in a source with independently established truth. SourceBound retains evidence spans, source versions, subject–relation–object binding and revision-aware checks before admitting a record.

What was measured

A bug-fixed known-fixture replay reports 27 unit tests; 14,000 synthetic pages yielded 6,000 fixture-labeled retained assertions with zero extra fixture emissions. These are synthetic and post-hoc regression checks, not held-out natural-web accuracy.

Candidate assertion→Source + span + version→Binding and consistency gates→Admit / quarantine

Open evaluation: domain-held-out annotation, precision/recall at matched coverage, false-assertion rate, latency and cost. No world-truth or universal-safety guarantee is asserted.

02 / COMPUTATIONAL MATHEMATICS · OPTIMIZATION

Erdős minimum overlap

Turn a numerical candidate into an inspectable exact-rational construction.

Public finite construction
External mathematical referee open

Problem and approach

Minimize a worst-case translation-overlap functional subject to mass and range constraints. A 131,072-cell step-function witness is stored as integer heights with denominator 270; the audit checks mass, bounds and signed shifts using integer arithmetic.

What was measured

The archived exact objective is 0.380856370118029325…, an upper-bound construction rather than a proof of global optimality. The public curated asset was anonymously downloaded, hash-verified and replayed in CI, including every signed grid shift.

Finite witness→SHA-256 + mass + bounds→Exact shift audit→Upper-bound certificate

Scope: the 131,072-entry candidate exceeded the Arena's 100,000-entry limit. Its mathematical construction and competition eligibility are separate; the accepted leaderboard entry has unresolved source-file provenance.

03 / RESEARCH ENGINEERING · VERIFICATION SYSTEMS

The discovery-to-review toolchain

Interactive research tools with explicit evidence boundaries, adversarial checks and regression tests.

Browser demos + GitHub Actions
Research workflow, not autonomous theorem proof

Problem and approach

Research artifacts often lose their assumptions while moving between ideation, counterexample search, checking and presentation. NIGHTFALL provides a bounded workflow across Frontier, Orchestrator, the Imaginary Adversary, Referee, Claim Lab and evidence-linked investigations.

What was tested

The repository includes targeted Node regression suites, site-link and metadata validation, headless mobile/desktop browser checks, corrupted-input controls and GitHub Actions workflows. An exact local demonstration is intentionally kept distinct from external peer review or a deployed ML service.

Frame question→Generate and attack→Check finite claims→Archive scope

Reproduce: python3 scripts/check_site.py, node scripts/test_adversary.cjs and node scripts/test_companion_handoff.cjs from the repository root. The full browser matrix runs in CI.

03 / RESEARCH JUDGMENT

Negative findings
count as results.

Proof After Scarcity — causal verification triage

In a retrospective, outcome-aware 20-case stress test, an uncalibrated triage method chose the documented weak-link category first in 8/20 cases. Two simpler baselines achieved 11/20. The failure is published instead of being recast as a win. Prospective predictions, blinded labels and complete graph artifacts remain separate open work.
