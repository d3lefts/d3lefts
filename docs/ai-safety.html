01 / COMMON FOUNDATION

One precise boundary.

A safety property can be decided from a fixed observation only when every pair of executions giving the same observation requires the same decision. This classical factorization result supplies a common language for agent-monitor design, without claiming novelty for the underlying mathematics.

STATIC OBSERVATION / FACTORIZATION
F = d ∘ R  ⇔  ker(R) ⊆ ker(F)

R is the actual observable view; F is a specified safety label. A restricted protocol still needs the induced decision rule to be implementable in its permitted class. This qualification corrects an earlier draft.

From this foundation follow a maximal sound admission rule, explicit collateral denial from mixed-label observation classes, a weighted-set-cover model of evidence repair, and policy-specific provenance and history requirements.

04 / SEPARATE IMPLEMENTATION

SourceBound.

An auditable publication gate for web-extracted source assertions, distinct from the abstract safety theorems. It checks source-version provenance, a restricted evidence-to-triple binding, browser-visible evidence, temporal conflicts, and revision-aware links before admission.

Guarantee boundary: restricted-source assertion traceability is different from external truth. The next required validation is a preregistered, domain-held-out natural-web study comparing unsupported published edges and answer quality at matched recall.
