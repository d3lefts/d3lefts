A short technical portfolio for engineers and research scientists. Each case records the difficult problem, the implemented mechanism, what actually passed, and what remains unproved.

CASE 01 / AGENT EVALUATIONOfficial scored fixture / scoped

When an agent changes the wrong thing.

Problem: A repository modification can pass the legitimate task while silently weakening a separate security control.

Work: Source-exact attack synthesis, isolated AWS CDK compilation, official main/side scorers, policy decisions, tamper tests and separately implemented receipt replay.

Result: Two constrained local-model source omissions were distinct and executable. Complete mission audit and baseline-pinned protection denied both. This does not establish unrestricted native-agent competence or production safety.

CASE 02 / MATCHED BASELINESReplayed & benchmarked / scoped

A faster check is not automatically a better method.

Problem: Determine whether a certificate-directed monitor reduces verification cost without sacrificing legitimate authorization or adversarial rejection.

Work: Eight pinned candidates, matched early-exit comparator, 100 warmup-excluded host-side calls per candidate, independent negative receipt audit.

Result: 328.80 μs versus 445.28 μs for the unoptimized full verifier, but 329.03 μs for an equally informed comparator: essentially a tie. No demonstrated frontier advantage.

CASE 03 / FORMAL VERIFICATIONNamed Lean receipts / scoped

Certificates that say exactly what was checked.

Problem: A plausible theorem statement, a passing test, a partial Lean lemma and a kernel-certified theorem cannot be treated as equivalent.

Work: Reproducible Lean/Mathlib pins, original-source representations, named axiom checks, independent kernel replay, source custody and Proof Passports.

Result: A selected 107-module Q2 Lake build passed named checks and kernel replay in its recorded environment. The historical infinite-product limit was conditional, not a completed universal theorem.

02 / TECHNICAL REVIEW / FIVE-MINUTE PATH

Skip the claims.
Inspect the receipts.

  1. Start with the failure. Two constrained local-model edits altered different FSx policy actions and passed the official ControlArena main/side task pair.
  2. Check the baseline. Eight candidate templates were evaluated against a full verifier, a cheap necessary-condition precheck and an equally informed comparator.
  3. Read the negative finding. The optimized method ties the strong matched baseline; native unrestricted agent execution had no valid tool calls in the earlier local run.
  4. Replay the certificate. Follow pinned source, test artifacts, receipt hashes, proof dependencies and explicit missing guarantees.
Open the evidence ledger ↗

Why this is research engineering, not a collection of demos.

The working loop is: define a falsifiable task; run the official environment; isolate the failure mode; compare against the strongest matched alternative; write an independent checker; preserve the source, replay and negative result; then change the next hypothesis. The shared infrastructure matters as much as any one score.

Independent source implementations and AI criticism are internal cross-checks. They do not imply independent human peer review.
