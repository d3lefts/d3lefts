## Reproducibility for one-human operation

The human research owner can operate the full cycle without a required outside reviewer: [Frontier](frontier.html) defines a bounded question → [Orchestrator](orchestrator.html) separates construction and falsification lanes → [Discovery Engine](discovery.html) explores operators → [Imaginary Adversary](adversary.html?domain=sidon#workbench) attempts bounded counterexamples → [Referee](referee.html?domain=sidon#workbench) recomputes exact finite evidence → [Claim Lab](claim-lab.html) stages a consented local evidence record. The recommended entry is the [five-step 30-point Sidon replay](exact-research.html#guided-replay). **An internal agent or independent code path is internal validation, not external peer review**, and no tool autonomously publishes a theorem.

External contributions remain welcome but are not a website publication dependency. Existing source-grounded reviewer tasks remain available:

1. **Four historical review issue threads are live**: [#1 Erdős](https://github.com/d3lefts/d3lefts/issues/1), [#2 Werner](https://github.com/d3lefts/d3lefts/issues/2), [#3 finite-field](https://github.com/d3lefts/d3lefts/issues/3), [#4 AI safety](https://github.com/d3lefts/d3lefts/issues/4).
2. The [two approved curated ZIPs](https://github.com/d3lefts/d3lefts/releases/tag/nightfall-research-2026-10-28) are public. Run `python3 scripts/download_nightfall_curated_assets.py public-assets` for fresh anonymous downloads with complete manifest checks. The [evidence page](evidence.html) links both assets and the exact replay. Historical master ZIPs remain private; do not ask the owner to upload them.
3. Keep the claim-status ladder and external source dependencies accurate whenever a reviewer reports a counterexample or correction.

The design takes inspiration from editorial research portfolios, while its layout, identity, copy, and review-oriented content are original to NIGHTFALL. All third-party links and mathematical source authors retain their proper attribution.
