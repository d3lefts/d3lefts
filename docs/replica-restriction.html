01 / EXACT TRANSFER FRONTIER

What is preserved—and what is not.

Draw finitely many independent replicas of each original product coordinate. Let a selector pick one replica per coordinate according to weights πi,a. Define the selector collision probability λi = Σa πi,a2, and qi = 1 − λi.

The original Hoeffding interaction energies ES obey two exact averaged identities:

E[ Var(g) ] = Σ_{S nonempty} (1 − Π_{i in S} λ_i) E_S
E[ I_i(g) ] = q_i I_i(f)

Yet the best possible universal expected-maximum comparison has multiplier

sup_{source, bounded f} E[ max_i I_i(g) ] / max_i I_i(f)
       = Σ_i q_i.

The minimum fraction of variance preserved for every source function is β = min_i q_i. Thus any such scheme has sharp worst-case amplification A = Σ_i q_i ≥ n β. Equality occurs for equal qi. For ordinary fair two-sample restrictions: A = n/2 and β = 1/2.

02 / EXACT OBSTRUCTION

A rare additive family is sharp.

For independent Bernoulli(p) coordinates take fp(x) = (x1 + ··· + xn)/n, bounded between zero and one. Original maximum influence is p(1 − p)/n². The expected maximum restricted influence comes from exactly one activated replica in the rare-event limit p → 0. Summing its first-order weight yields Σ_i q_i, showing that no smaller general multiplier is possible—even for degree-one functions.

The theorem rules out a particular proof operator: averaging an independently sampled Boolean (or finite-replica) maximum-influence estimate into a dimension-independent original-source bound. It does not refute quadratic influence Q2 or exclude a different, correlated or history-adaptive reduction.

03 / REPRODUCIBILITY

The certificate is inspectable.

One exact Fraction checker exhaustively enumerates original input tables and weighted replica arrays, reconstructs Hoeffding energies and resampling influences, and checks the formulas on biased/zero-mass alphabets and degree-three examples. A second, separately implemented checker verifies the rare-event sharpness coefficient through direct one-hot enumeration. Both were run locally; the branch includes a CI workflow for remote replay and source hashing.
