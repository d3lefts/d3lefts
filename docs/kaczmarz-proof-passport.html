01 · Exact statement

BEST ITERATE / CONSISTENT LINEAR SYSTEM

For a consistent real system Ax* = b, start from y₀. At each step project onto the row hyperplane whose normalized residual |⟨aᵢ,yₜ⟩−bᵢ|² / ||aᵢ||² is largest. Ignoring zero rows, after constructing K ≥ 1 iterates including y₀, the following holds:

min0 ≤ t < K ‖Ayt − b‖₂ ≤ (‖A‖F / √K) ‖y₀ − x*‖₂

Taking K = ⌈‖A‖²F / δ²⌉ yields an iterate with residual at most δ‖y₀−x*‖, using at most K−1 projections. For δ = ε‖A‖op and n columns:

K ≤ ⌈n / ε²⌉

In the original square invertible setting with y₀=0, this removes the logarithm from the published existential projection-count estimate; ‖y‖≤2‖x*‖ follows from projection stability. The original question is in Steinerberger's March 2026 problem list, under “Approximate Solutions of Linear Systems.”

02 · The proof mechanism

ANALYTIC / NO APPROXIMATIONS

Write eₜ=yₜ−x*, rₜ=Aeₜ, and W=‖A‖²F. Orthogonal projection loses exactly the squared normalized selected residual. The largest row contribution dominates its row-norm-weighted average:

‖et‖² − ‖et+1‖² = maxi |(rt)i|² / ‖ai‖² ≥ ‖rt‖² / W

Sum over t=0,…,K−1. The left side telescopes and is bounded by ‖e₀‖². Consequently Σₜ‖rₜ‖² ≤ W‖e₀‖²; one of the K terms is no larger than their average. No condition number, unobserved solution, or minimum singular value enters row selection.

The companion stopping-time argument obtains Eτ ≤ ‖A‖²F / δ² for the original randomized row-norm sampling when τ is the first successful residual. It is not a fixed-time tail bound.

03 · Evidence dimensions

SEPARATE GATES / NO AUTOMATIC PROMOTION
Validity
Exact written proof via Pythagoras, weighted maximum and telescoping; zero-row, consistency and initial-error edge cases stated. Independent human mathematical referee review is not complete.
Reproducibility
Python 3 standard-library rational checker; 240 systems and 12 greedy steps each (2,880 updates), plus a coefficient-sharpness negative control. Finite tests are not a proof of generality.
Originality
Open. Maximum-distance Kaczmarz and the energy decrement are classical. The March 2026 problem list is evidence of a listed question, not proof that this corollary was previously unknown.
Significance
Log-free existential number of projections for a best-prefix iterate. No claim about number of arithmetic operations, free row selection, the final iterate of a fixed randomized run, or the inconsistent-system model.
