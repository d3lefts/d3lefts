01 · Exact statement

BEST ITERATE / CONSISTENT LINEAR SYSTEM

For a consistent real system Ax* = b, start from y₀. At each step project onto the row hyperplane whose normalized residual |⟨aᵢ,yₜ⟩−bᵢ|² / ||aᵢ||² is largest. Ignoring zero rows, after constructing K ≥ 1 iterates including y₀, the following holds:

min0 ≤ t < K ‖Ayt − b‖₂ ≤ (‖A‖F / √K) ‖y₀ − x*‖₂

Steinerberger's unscaled Theorem 1 target: Set K = ⌈‖A‖²F / ε²⌉. A qualifying iterate appears with at most K−1 projections and satisfies ‖Ay−b‖₂ ≤ ε‖y₀−x*‖₂ and ‖y−x*‖₂ ≤ ‖y₀−x*‖₂. This matches Theorem 1, not merely its abstract. For the abstract's scaled target ε‖A‖op‖x*‖ from y₀=0, use ‖A‖²F ≤ n‖A‖²op:

K ≤ ⌈n / ε²⌉

For the source-matched, unscaled residual threshold, Steinerberger's published Theorem 1 states k ≤ 2 log(‖A‖op/ε) ‖A‖²F / ε². The displayed bound removes that logarithm in the same existential projection-count model. For the square invertible case with y₀=0, ‖y‖≤2‖x*‖ follows from stability. The original question is in Steinerberger's March 2026 problem list, under “Approximate Solutions of Linear Systems.”

02 · The proof mechanism

ANALYTIC / NO APPROXIMATIONS

Write eₜ=yₜ−x*, rₜ=Aeₜ, and W=‖A‖²F. Orthogonal projection loses exactly the squared normalized selected residual. The largest row contribution dominates its row-norm-weighted average:

‖et‖² − ‖et+1‖² = maxi |(rt)i|² / ‖ai‖² ≥ ‖rt‖² / W

Sum over t=0,…,K−1. The left side telescopes and is bounded by ‖e₀‖². Consequently Σₜ‖rₜ‖² ≤ W‖e₀‖²; one of the K terms is no larger than their average. No condition number, unobserved solution, or minimum singular value enters row selection.

First-hit certificate: If all of the first K iterates had residual greater than ε‖e₀‖, the summed drops would exceed Kε²‖e₀‖²/W ≥ ‖e₀‖², contradicting nonnegative squared error. Stopping at the first qualifying iterate makes it the final iterate of the stopped, adaptive sequence. This does not give a fixed-time guarantee for an unstopped randomized run.

The companion stopping-time argument obtains Eτ ≤ ‖A‖²F / δ² for the original randomized row-norm sampling when τ is the first successful residual. It is not a fixed-time tail bound.

03 · Evidence dimensions

SEPARATE GATES / NO AUTOMATIC PROMOTION
Validity
Exact written proof via Pythagoras, weighted maximum and telescoping; zero-row, consistency and initial-error edge cases stated. Independent human mathematical referee review is not complete.
Reproducibility
Python 3 exact-rational checks: 240 seeded systems × 12 steps (2,880 updates), plus a distinct exhaustive 6,552-case, 52,416-step two-column checker. Finite checks test algebra, not novelty or universal truth.
Originality
Not established. Maximal-violation relaxation goes back to Agmon and Motzkin–Schoenberg (1954); maximum-distance Kaczmarz and energy descent are classical. This exact corollary may be implicit in earlier analyses. A listed question is not proof of historical novelty.
Significance
Log-free existential number of projections for a best-prefix iterate. No claim about number of arithmetic operations, free row selection, the final iterate of a fixed randomized run, or the inconsistent-system model.
