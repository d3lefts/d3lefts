What the guard cannot see
it cannot reliably decide.

A guard cannot make an exact safety decision when safe and unsafe executions are indistinguishable in the record it sees. This is an information limit, not proof that a particular deployed defense is sound. Computation, authenticated provenance and authority to act impose further distinct constraints.

01 / INFORMATION

Observation fibers determine what is decidable

F = d ∘ R   ⇔   F constant on fibers of R

Let F be the required safety predicate and R the observable execution record. Exact decision from R is possible precisely when F agrees on indistinguishable executions. This factorization criterion is established mathematics, not a newly discovered theorem. A restricted protocol family additionally needs the induced decoder to be implementable within that family; the unrestricted converse was corrected after a counterexample.

02 / ENFORCEMENT

Maximal sound guards must deny ambiguous cases

g(v)=1   ⇔   every x in R⁻¹(v) is safe

Under universal one-shot soundness over the declared execution universe, no guard using only v can admit a fiber containing an unsafe execution. Randomizing the decision does not evade zero-unsound-admission. The practical cost is collateral denial when benign and harmful executions collapse to the same abstraction.

On a fixed 60-task AgentDojo analysis with 25 injection cases, 23/25 injected side-effecting tool calls share their tool name with a legitimate action; the specified name-only sound guard has a 45/60 legitimate-task denial floor. These are historical ground-truth counts for a particular view, not measured production false-positive rates or an evaluated end-to-end protection claim.

03 / REPAIR

Additional evidence has a price

Given a finite catalogue of candidate trusted observations, selecting the cheapest set that separates every unsafe/safe indistinguishable pair is weighted set cover. Provenance summaries need policy-specific congruence classes; unordered taint sets are sufficient only under suitable algebraic restrictions. Finite-window monitors, controllable actions and decentralized vetoes require different notions of sufficiency.

Weighted set cover, classical automata and supervisory control are imported foundations. The proposed contribution is the agent authorization model and the scope-controlled interface between them, not an originality claim for those ingredients.

04 / IMPLEMENTATION

SourceBound: provenance is not world truth

SourceBound admits restricted source assertions with version, field-binding, rendered-evidence and temporal checks. The bug-fixed historical evaluation reports 27/27 unit tests and 14,000 synthetic pages yielding 6,000 fixture-labeled retained triples with zero extra fixture emissions. Previously seen adversarial paraphrases are regression cases, not held-out evaluation.

A source can consistently assert something false. Source provenance alone cannot establish external truth, and a blind, domain-held-out natural-web performance study remains outstanding. The earlier counterfactual resource-frontier claim was refuted and explicitly excluded.
