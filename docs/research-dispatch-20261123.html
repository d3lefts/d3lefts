Route 1: query-local Wyner information transfer

A b-local encoding with r-query recovery of each latent coordinate transfers the Route 1 simulator to original observed-coordinate queries at depth r·q. A duplicated-source family separates raw ambient Wyner information from latent information by a growing gap.

Scope
Bounded degree-d observed targets, explicitly finite source and access model, component-wise b-local encoding, source TV slack; general-latent Route 1 core already formalized separately in #970.
Mechanism
Pull each observed degree-d cylinder through a b-local map (degree at most bd), then substitute a costed deterministic adaptive decoder for each latent query.
Evidence
Paper argument in merged #1150 and separate exact finite cylinder check. Earlier Route 1 named Lean theorem #970 is a dependency, not a certificate for this transfer. End-to-end b-local candidate #1157 was closed unverified.
Limitation
No exact-head kernel certificate for the b-local terminal; the information-gap example is not a lower bound on optimal original-oracle query complexity, and no efficient classical runtime is shown.
Next decisive test
Reopen source-exact b-local DTree, degree-pullback, and final terminal under a green Lean+leanchecker receipt; independently audit the physical query interface.
Credit
NIGHTFALL paper extension of earlier Route 1 #970 and classical Wyner information.

Affine-code and graph-phase Wyner identity

For Y uniform on an affine code a+L of dimension d with r free coordinate axes, the proposed multivariate raw-coordinate identity is C_W(Y)=(d−r) log₂q. Graph-edge squared-intensity measurements specialize the paper result to (n−1−b) bits, where b is the number of bridges.

Scope
Finite affine codes over F_q and finite multivariate Wyner information; graph-phase specialization uses noiseless squared edge-sum readings of ±1 signs on a connected graph.
Mechanism
Each positive-mass conditional-product component lies in a rectangular piece of the code; free-coordinate fibers describe precisely which coordinates require no shared latent.
Evidence
Paper proof #1095; merged #1151 verifies scoped support/fiber structure. Independently source-checked finite-mixture entropy identity #1168 is a separate component, not the complete Wyner infimum proof.
Limitation
Global equality C_W=(d−r)log₂q and arbitrary-latent entropy infimum remain outside the currently demonstrated end-to-end Lean certificate. Novelty and external review are open.
Next decisive test
Kernel-compose source support, cardinality, entropy, and attaining latent; independently check infimum normalization.
Credit
NIGHTFALL collaboration; classical finite-field affine-code and Wyner antecedents acknowledged.

Physical three-query phase-block circuit bridge

A normalized finite matrix-query circuit with the specified raw squared-intensity address oracle admits a real, original-address DTree decoder using at most 3 queries per decoded block, yielding a scoped scalar-acceptance simulation through Route 1.

Scope
Finite normalized coordinate-oracle circuits; eight-state real phase-block encoding; raw intensity readings; bounded scalar acceptance. Cost is measured in original physical oracle readings.
Mechanism
Group input degrees without inflation, decode each independent phase block by an actual adaptive three-reading tree, then reuse the Route 1 source terminal.
Evidence
Merged #1128 exact-head pinned Lean compilation, independent leanchecker and trusted-axiom audit passed, run #45068560816, including the normalized final declarations.
Limitation
Not a coherent-state simulation, general nonlinear/nonlocal amplitude-oracle result, polynomial-time classical implementation, or worldwide originality determination.
Next decisive test
Independent external theorem-scope audit, complexity accounting and test for larger block families.
Credit
NIGHTFALL formalization with source credit to #1084, #1105, #1118 and #1133 and standard polynomial-method antecedents.

Product-sphere zero-fiber obstruction

A self-contained author-side proof for the classical product-sphere equivariant zero statement combines augmented homotopy, smooth regular-value geometry, an actual interval-orbit action and a boundary-count contradiction.

Scope
n≥1 and the explicitly dimension-restricted r,s<n product-sphere setting; topological zero theorem is classical, distinct from its phase-retrieval application.
Mechanism
Represent the zero locus as a smooth one-manifold with true endpoint charts; use the free (Z/2)² orbit structure to force more boundary points than geometry permits.
Evidence
Detailed manuscript in draft #1147 with separately integrated local Lean chart/rank subresults. Whole zero-fiber global assembly and unconditional theorem do not have an end-to-end Lean certificate.
Limitation
Independent mathematical scrutiny, full formal atlas/compactness/gluing and exact terminal Lean proof remain open. No priority claim over classical topological theorems.
Next decisive test
Adversarially check endpoint regularity, connected-component classification and global group action; compile the exact final statement.
Credit
NIGHTFALL proof development; Chan–Chen–Frick–Hull and classical equivariant topology retained as antecedents.

02 / DISCOVERY PROCESS · 23 NOVEMBER UPDATE

Make the next result cheaper to verify.

These are process controls, not theorem claims. A comparator passing tests does not prove a new mathematical result, and internal AI-agent criticism does not count as independent external review.

CONTRACT BEFORE CANDIDATE

Freeze the claim, not just the code.

The merged externally frozen comparator pilot #1171 checks an immutable theorem target, exact type, source bytes, compiler lock, axiom dependencies and compilation receipt against trusted main. Its nine negative controls test fail-closed behavior. The pilot is a wrapper for one smoke theorem; the existing Lean bridge supplies kernel replay. The site makes no claim of a full-registry rollout.

TWO DISTINCT ENGINES

Construct; then attack.

Design a falsifier before viewing the candidate. Replay exact inputs, challenge proof assumptions, search edge cases, audit same-model baselines and independently run checkers where available. Keep conjecture, numerical witness, source-exact Lean declaration, external review and originality as distinct promotions.

SOURCE-EXACT REPLAY

Keep custody when instances converge.

Bind a certificate to source/commit hashes, dependency closure, named declarations, pinned compiler, standard axioms and run URL. Prefer small, reproducible commits that survive parallel branch movement. #1168 demonstrates a narrow source-verified identity, while #1154 demonstrates why an unexecuted terminal must stay pending.

OPERATIONAL SAFETY

Unjam queues without weakening proof checks.

Cleanup PRs #1164 and #1169 target obsolete queued runs using current-head guards and bounded retries; they are infrastructure fixes, not Lean theorem receipts. The current PR head, current main head and historical failures must be preserved. A platform refusal to cancel remains a reported blocker.

RESOURCE SEMANTICS

Measure the query people actually make.

Route 1 and phase-block work count original physical sensor accesses rather than silently swapping in a free latent oracle. Borrow the explicit expected-cost and frozen-specification lessons of Shirobokov et al., Discovering formally verified quantum programs with AI, with original authors credited. NIGHTFALL has not duplicated that paper's quantum algorithm gains.

DISCOVERY GRAPH

Preserve transfer conditions.

Record Problem → Representation → Mechanism → Operator → Construction → Certificate → Limit → Transfer. A proposed transfer must name its matching oracle, distribution, symmetry and error metric. Revisit a plateau by changing representation or operator—not by rebranding a failed terminal.
