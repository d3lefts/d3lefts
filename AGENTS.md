# NIGHTFALL repository operating instructions

Read `research/nightfall/TEAM_ROLES_20261029.md` and the active assignment before research. **Lean certification runs on GitHub Actions using `.github/actions/setup-nightfall-lean` and `docs/lean-compiler-lock.json`.** Do not install, restore, require, or substitute a local Lean/Mathlib compiler in the ChatGPT research sandbox (4 GiB memory constraint). Local work is source editing, exact non-Lean computation, and receipt inspection only. Do not remove or replace the pinned GitHub workflows with local infrastructure. Reuse authenticated exact-source named receipts and exact-pin dependency caches; do not rerun unrelated proof closures. Preserve all proof sources, claims, and receipts. New certification requires exact source identity, actual successful kernel checking and named axiom audit; metadata checks alone are not certification. Compiler pin changes require separate authorization and compatibility verification.

For every new or changed Lean source, reconcile exact source custody and regenerate `docs/proof-passport-v3.json` using `node scripts/sync_proof_passports_v3.cjs --write` before pushing. Development kernel replays check implemented declarations; manuscript completeness is a separate fail-closed release gate. Do not launch known-failing challenges containing undeclared identifiers as ordinary proof CI. Never promote partial proofs or bypass source-hash checks.
